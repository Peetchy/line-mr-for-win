# มีอะไรใหม่ใน LINE MR

## รุ่น 0.5.6

### ปุ่มลัด
- Alt+T ในรายการข้อความตอนนี้ใช้แปลข้อความที่เลือก (คำสั่ง "แปล" ในเมนูข้อความของ LINE) ส่วนการแปลงข้อความเสียงเป็นข้อความย้ายไปที่ Alt+Shift+T

### แปลงข้อความเสียงเป็นข้อความ
- ใหม่: กด Alt+Shift+T บนข้อความเสียง (หรือเลือก "แปลงเสียงเป็นข้อความ" ในเมนู) เพื่อแปลงเป็นข้อความบนเครื่องนี้ ข้อความจะเปิดในหน้าต่างที่อ่าน แก้ไข และคัดลอกได้ ปิดไว้เป็นค่าเริ่มต้น เมื่อเปิดในการตั้งค่า NVDA หมวด LINE MR จะดาวน์โหลดโมเดลเสียงที่เลือกไว้ครั้งเดียว มี 6 โมเดล: Typhoon Whisper Turbo (874 MB ค่าเริ่มต้น เหมาะกับภาษาไทยที่สุด ใช้กับภาษาอังกฤษและญี่ปุ่นได้ด้วย ใช้หน่วยความจำน้อยที่สุดในกลุ่ม Typhoon), Typhoon Whisper Medium และ Large v3 (ภาษาไทยเท่านั้น Large v3 แม่นยำที่สุดแต่ช้ามาก) และ Whisper Small, Medium, Large v3 Turbo ของ OpenAI (หลายภาษา) หรือ "เลือกไฟล์โมเดลเอง" สำหรับโมเดล whisper.cpp ของคุณ ซึ่ง LINE MR จะตรวจก่อนใช้ หน้าต่างก่อนแปลงแต่ละครั้งถามทั้งโมเดลและภาษา ดูคู่มือ หัวข้อ "แปลงข้อความเสียงเป็นข้อความ"

### บันทึกข้อความ
- ใหม่: Ctrl+S ในรายการข้อความบันทึกข้อความที่เลือก รูป วิดีโอ ไฟล์ และข้อความเสียง: ใช้คำสั่งบันทึกเป็นของ LINE (LINE ถามที่เก็บ) ข้อความตัวอักษร (ครบทั้งข้อความ แม้ข้อความยาว) ตำแหน่ง และรายชื่อติดต่อ: บันทึกเป็นไฟล์ข้อความ (.txt) โดย LINE MR ถามที่เก็บ สติกเกอร์ การโทร วันที่ และข้อความแจ้งเตือนในแชท: LINE MR แจ้งว่าไม่รองรับ ที่อื่น Ctrl+S ทำงานตามปกติ และเปลี่ยนปุ่มได้ใน Input gestures ของ NVDA

### รูปและวิดีโอ
- บันทึกหรือแชร์รูปและวิดีโอหลายรายการพร้อมกันได้แล้ว (#9): ในหน้าต่างรูปและวิดีโอของแชท (เมนูแชท) กด Space เพื่อเลือกรายการ NVDA จะบอกว่าเลือกไว้หรือไม่ กด Tab ไปที่แถบของ LINE ใต้ตาราง (จำนวนที่เลือก, แชร์, ส่งไปยัง Keep Memo, ดาวน์โหลด, ยกเลิก) ดาวน์โหลดจะถามโฟลเดอร์ ยกเลิกจะยกเลิกการเลือกทั้งหมดแล้วกลับไปที่ตาราง ส่วน Enter ยังเปิดรายการเหมือนเดิม รูปในอัลบั้มที่ส่งมาในแชทก็อยู่ในหน้าต่างนี้ LINE เองบันทึกรูปหลายรูปพร้อมกันได้จากหน้าต่างนี้เท่านั้น

### รายการแชท
- จำนวนที่ยังไม่อ่านอ่านว่า "ยังไม่ได้อ่าน 3 ข้อความ" (เดิม "ยังไม่อ่าน 3") ยังอยู่ท้ายแถวของแชทเหมือนเดิม
- กลุ่มและโอเพนแชทบอกประเภทต่อจากชื่อแชท เช่น "DHCB, กลุ่ม, สมาชิก 37 คน, ..." และ "English talk, โอเพนแชท, สมาชิก 3051 คน, ..." (#5) ส่วนบัญชีทางการยังแยกจากเพื่อนไม่ได้ เพราะ LINE ไม่ได้ให้ข้อมูลที่บอกได้

### การตั้งค่า
- การตั้งค่า NVDA หมวด LINE MR แสดงว่าตัวเชื่อมทำงานอยู่หรือไม่ และมีปุ่มตัดการเชื่อมต่อ (ใช้ LINE ตามปกติโดยไม่มี LINE MR) หรือเชื่อมต่ออีกครั้ง ทั้งสองแบบ LINE จะเริ่มใหม่
- เมื่อถอน LINE MR ใน Add-on Store ของ NVDA ตัวเชื่อมจะถูกลบออกจาก LINE โปรแกรมโทร และหน้าต่างดูรูปของ LINE ด้วย รวมถึงโฟลเดอร์ `%LOCALAPPDATA%\LineMR` ถ้า LINE เปิดอยู่ จะยังใช้ตัวเชื่อมต่อไปจนกว่าจะออกจาก LINE

### ข้อความ
- ข้อความยาวและข้อความที่ได้รับบางข้อความไม่มี "แสดงความรู้สึก" ในเมนู เพราะถูกมองว่าเป็นข้อความแจ้งเตือนในแชท แก้แล้ว (#3)
- การเปิดแชทด้วย Enter คงตำแหน่งของ LINE ไว้ (เช่น ข้อความแรกที่ยังไม่ได้อ่าน) แทนการกระโดดไปข้อความล่าสุด และ Shift+Tab จากช่องพิมพ์ข้อความกลับไปที่รายการข้อความจะอยู่บนจอเดิม (ข้อความที่อ่านล่าสุดถ้ายังเห็นอยู่ ไม่เช่นนั้นข้อความแรกบนจอ) ร่วมพัฒนาโดย wengweng0312 (#20)
- ในรายการข้อความ Alt+R ตอบกลับข้อความที่เลือกแล้วไปที่ช่องพิมพ์ข้อความ Delete ลบข้อความ และ Shift+Delete ยกเลิกข้อความ (เป็นรายการในเมนูข้อความของ LINE ถ้า LINE ถามยืนยัน ให้ตอบเอง) ที่อื่นปุ่มเหล่านี้ทำงานตามปกติ และเปลี่ยนปุ่มได้ใน Input gestures ของ NVDA (ร่วมพัฒนาโดย wengweng0312)
- การเลือก "ตอบกลับ" ในเมนูของข้อความจะย้ายไปที่ช่องพิมพ์ข้อความ (ร่วมพัฒนาโดย wengweng0312)
- ระหว่างตอบกลับ ไปถึงแถบเหนือช่องพิมพ์ข้อความได้แล้ว: Shift+Tab จากช่องพิมพ์ข้อความไปที่ "ยกเลิกการตอบกลับ" และ "ไปที่ข้อความต้นฉบับ" กดยกเลิกแล้วกลับไปที่ช่องพิมพ์ข้อความ
- ตัวเลือกใหม่ในการตั้งค่า NVDA หมวด LINE MR: "แสดงชื่อผู้ส่งในแชทหนึ่งต่อหนึ่ง" อ่านชื่ออีกฝ่ายก่อนข้อความของเขา (ปิดไว้เป็นค่าเริ่มต้น) ข้อความยาวของคุณเองที่ LINE ไม่ได้วาดเวลาไว้ จะอ่านว่าเป็นของคุณ (ร่วมพัฒนาโดย wengweng0312)
- Enter ในรายการแชทจะอยู่ที่ช่องพิมพ์ข้อความของแชทที่เปิด: บางครั้ง LINE ย้ายโฟกัสไปที่รายการข้อความเมื่อแชทโหลดเสร็จ ในแชทที่เปิดอยู่ Tab จะไปตามลำดับ รายการข้อความ ช่องพิมพ์ข้อความ แล้วปุ่มด้านล่างเสมอ
- การแท็ก @ ในแชทกลุ่ม: หลังพิมพ์ @ ลูกศรขึ้น/ลงจะอ่านรายชื่อสมาชิกที่ LINE แนะนำ พิมพ์ต่อเพื่อกรองชื่อ และ Enter เลือกสมาชิก ก่อนหน้านี้ลูกศรใช้ไม่ได้ในรายการนี้ (ร่วมพัฒนาโดย wengweng0312) ในช่องพิมพ์ข้อความ สมาชิกที่เลือกจะอ่านเป็น "@ชื่อ" (ก่อนหน้านี้ NVDA ไม่อ่านอะไรเลย)
- ข้อความอ่านจากข้อความของ LINE เอง (LINE 26.6 ขึ้นไป): มีชื่อผู้ส่งและเวลาทุกข้อความ ข้อความตอบกลับครบ ("X ตอบกลับข้อความของ Y ...") และชื่อไฟล์เต็ม รวมถึงข้อความที่ไม่ได้อยู่บนจอ LINE MR เติมสิ่งที่ LINE ไม่บอก: "คุณ" หน้าข้อความของคุณเอง สติกเกอร์และการโทร และความรู้สึก (ร่วมพัฒนาโดย wengweng0312) ความยาวที่ตัวเชื่อมอ่านเอง (การโทร และข้อความเสียงหรือวิดีโอที่ LINE ไม่ได้ให้ข้อความ) อ่านเป็นคำ: "7 วินาที", "10 นาที 54 วินาที" แทน "00:07", "10:54"
- ข้อความบอกส่วนที่ข้อความของ LINE ไม่มีด้วย: ขนาดไฟล์และวันที่โหลดได้ถึง ชื่อของตัวอย่างลิงก์ "ตำแหน่งที่ตั้ง" ก่อนที่อยู่ "รายชื่อติดต่อ" พร้อมชื่อ และ "อัลบั้มรูปภาพ" แทน "รูป" ข้อความตอบกลับอ่านคำตอบก่อน: "X, ตอบกลับ Y: <คำตอบ>, ข้อความเดิม: <ข้อความที่อ้างถึง>" ใน Keep Memo ทุกข้อความอ่านว่า "คุณ" และรู้จักเวลาและสถานะอ่านแล้วของ LINE ภาษาญี่ปุ่นและจีน ข้อความของคุณจึงอ่านว่า "คุณ" ในภาษาเหล่านั้นด้วย
- ตัวเลือกใหม่ในการตั้งค่า NVDA หมวด LINE MR: "อ่านชื่อผู้ส่งเฉพาะเมื่อผู้ส่งเปลี่ยน" (ปิดไว้เป็นค่าเริ่มต้น) ข้อความที่คนเดิมส่งต่อกันจะเริ่มที่เนื้อความเลย

## รุ่น 0.5.5

### การอัปเดต
- เมื่อติดตั้งจาก Add-on Store ของ NVDA ให้ Store ดูแลการอัปเดต LINE MR จะไม่ตรวจ GitHub อีก และหน้าการตั้งค่าจะแจ้งเรื่องนี้

### ไฮไลต์โฟกัส
- สำหรับผู้ใช้สายตาเลือนราง: กรอบสีเหลืองขอบดำแสดงว่าตัวควบคุมใดใน LINE มีโฟกัสอยู่ (รวมถึงแชท ข้อความ และรายการเมนู) เปลี่ยนสีและความหนา หรือปิดได้ในการตั้งค่าของ NVDA หมวด LINE MR

### การแก้ไข
- ใน NVDA 2025.4 หรือเก่ากว่า (NVDA 32 บิต) LINE MR ถามให้รีสตาร์ท LINE ซ้ำ ๆ ทั้งที่ใช้งานได้แล้ว ตอนนี้ LINE MR ตรวจพบได้ถูกต้องว่า LINE ทำงานพร้อม LINE MR แล้ว
- ในช่องพิมพ์ข้อความและช่องข้อความอื่น ๆ ลูกศรขึ้น/ลงอ่านบรรทัดตามที่แสดงบนจอ ย่อหน้ายาวที่ตัดขึ้นบรรทัดใหม่จะอ่านทีละบรรทัด แทนการอ่านทั้งย่อหน้าซ้ำทุกบรรทัด และบรรทัดว่างอ่านว่า "ว่าง" แทนการอ่านบรรทัดก่อนหน้าซ้ำ
- ลูกศรขึ้น/ลงในช่องพิมพ์ข้อความไม่ทำให้โฟกัสหลุด (เข้าไปที่แถบแนะนำสติกเกอร์และอิโมจิของ LINE ด้านบน) อีกแล้วระหว่างอ่านข้อความทีละบรรทัด
- กดลูกศรขึ้นที่ข้อความเก่าสุดที่โหลดอยู่ LINE จะโหลดข้อความที่เก่ากว่าเพิ่ม และกดขึ้นต่อได้ (ร่วมพัฒนาโดย wengweng0312)
- ช่องติ๊กในหน้าตั้งค่าที่เปลี่ยนด้วยแป้นพิมพ์ (เช่น การแจ้งเตือน > แสดงเนื้อหาข้อความ) ถูกบันทึกแล้ว (ร่วมพัฒนาโดย wengweng0312)
- ข้อความเสียงที่ LINE วาดเป็นหลายชิ้นจำได้ถูกต้องแล้ว กด Enter หรือ Space เพื่อเล่นได้ (ร่วมพัฒนาโดย wengweng0312)
- LINE ภาษาจีนตัวเต็ม: อ่านสถานะ "อ่านแล้ว" (已讀) และเวลา (下午 2:49) ไว้ท้ายข้อความ และข้อความที่ได้รับซึ่งเขียนว่า "已讀" จะไม่ถูกนับเป็นสถานะการอ่าน (ร่วมพัฒนาโดย Keyang556)

## เวอร์ชัน 0.5.4

### ข้อความยาว
- ในหน้าข้อความเต็มของข้อความยาว ("ดูเพิ่มเติม") NVDA จะพูดว่า "ขึ้นบรรทัดใหม่" เฉพาะตรงที่ผู้เขียนขึ้นบรรทัดใหม่เอง เหมือนใน Word ลูกศรขึ้น/ลงยังเลื่อนตามบรรทัดที่ LINE แสดง

### ข้อความ
- ข้อความที่มีลิงก์บางข้อความ (เช่น ลิงก์ YouTube) ถูกอ่านว่า "การโทร" ตอนนี้จะอ่านว่า "การโทร" เฉพาะข้อความการโทรของ LINE และการโทรแบบวิดีโอ ซึ่งเคยอ่านว่า "รูปภาพหรือสติกเกอร์" ก็อ่านว่า "การโทร" แล้ว

### รายการแชท
- แชทที่เปิดอยู่จะอ่าน "เลือกอยู่" ก่อนชื่อแชท แชทที่ปักหมุดไว้จะอ่าน "ปักหมุด" ต่อจากชื่อ

### สร้างแชท (แชท กลุ่มแชท โอเพนแชท)
- หน้าเลือกเพื่อนเปิดขึ้นมาที่ช่องค้นหา ลูกศรขึ้น/ลง Page Up/Page Down และ Home/End เลื่อนได้ทั้งรายชื่อ กด Space เพื่อเลือกเพื่อน ("checked") กด Tab ออกจากรายชื่อไปที่เพื่อนที่เลือกไว้ ("นำ <ชื่อ> ออก") และปุ่มต่อไป กด Shift+Tab กลับไปที่เพื่อนคนล่าสุดที่อ่าน
- หน้าตั้งค่าโปรไฟล์กลุ่มมีชื่อปุ่มครบ ได้แก่ เปลี่ยนรูปโปรไฟล์ เปลี่ยนภาพพื้นหลัง และแก้ไขชื่อกลุ่ม "สมาชิกเข้าร่วมกลุ่มโดยอัตโนมัติ" เป็นกล่องกาเครื่องหมาย กด Space เพื่อเปิด/ปิด
- สร้างโอเพนแชท: ช่องคีย์เวิร์ดและกล่องหมวดหมู่มีชื่อ ปุ่ม X ในช่องอ่านว่า "ล้างข้อความ" เมื่อกดต่อไป โฟกัสจะไปที่ "ชื่อเล่นของคุณในโอเพนแชท" และอ่านคำอธิบายว่าหน้านี้ใช้ทำอะไร
- สร้างโปรไฟล์ข้อความ (เปลี่ยนรูปโปรไฟล์ > สร้างโปรไฟล์ข้อความ): สีแต่ละสีเป็นกล่องกาเครื่องหมาย มีหมายเลขและชื่อสี ("สี 4: ชมพูอ่อน") กด Space เพื่อเลือก ปุ่มสีตัวอักษร / สีพื้นหลังเลือกว่าจะเปลี่ยนสีของอะไร กล่องรายการฟอนต์ชื่อ "ฟอนต์"

### โน้ต
- โพสต์ในโน้ต (กลุ่มและโอเพนแชท) อ่านชื่อผู้โพสต์ รูปหรือวิดีโอ จำนวนการแสดงความรู้สึกและความคิดเห็น และเวลา ลูกศรเลื่อนทีละโพสต์ กด Enter เพื่อเล่นวิดีโอของโพสต์ในตัวเล่นวิดีโอของ LINE (โฟกัสที่ปุ่มเล่น/หยุดชั่วคราว) และ Escape กลับไปที่โพสต์
- ปุ่ม Applications บนโพสต์เปิดเมนู: เปิด บันทึกเป็น... คัดลอกข้อความ และตัวเลือกเพิ่มเติม (เมนูของ LINE) ในตัวดูของ LINE กด Ctrl+S เพื่อบันทึกรูปหรือวิดีโอ

### การตั้งค่า
- ปุ่ม "มีอะไรใหม่" นี้ ในการตั้งค่าของ NVDA หมวด LINE MR

## เวอร์ชัน 0.5.3

### การแสดงความรู้สึก
- เมนูของข้อความ (ปุ่ม Applications) มีรายการ "แสดงความรู้สึก" ลูกศรซ้าย/ขวาเลื่อนระหว่าง สุดยอด ถูกใจ ตลก อิจฉา และเศร้า กด Enter เพื่อเลือก กด Escape เพื่อปิด บนข้อความที่คุณแสดงความรู้สึกไว้แล้ว รายการจะเป็น "ยกเลิกการแสดงความรู้สึก"
- ข้อความบอกว่ามีความรู้สึกอะไรบ้าง เช่น "ความรู้สึก: ถูกใจ" หรือ "ถูกใจ 3 คน"

### สติกเกอร์และอีโมจิ
- ชุดสติกเกอร์อ่านเป็นชื่อแทน "ชุดที่ 1"
- กด Enter ครั้งแรกเพื่อเลือกสติกเกอร์หรืออีโมจิและเล่นตัวอย่างของ LINE กดครั้งที่สองเพื่อส่ง
- กด Enter บนสติกเกอร์มีเสียงในแชทเพื่อเล่นเสียงอีกครั้ง

### แชท
- ในกลุ่ม ชื่อและจำนวนสมาชิกรวมเป็นรายการเดียว เมนูของข้อความมี "แสดงโปรไฟล์ <ชื่อ>"
- ค้นหาในแชท: กด Enter เพื่อค้นหา ลูกศรขึ้น/ลงไปที่ผลที่เก่ากว่า / ใหม่กว่า และ LINE MR อ่านผลให้
- เมนูเรียงลำดับบอกว่าเลือกตัวเลือกไหนอยู่

### รูปและวิดีโอ ลิงก์ ไฟล์
- ลูกศรเลื่อนไปตามรูป ลิงก์ และไฟล์ของแชท กด Enter เพื่อเปิด ปุ่ม Applications มีเปิด บันทึก คัดลอกลิงก์ และคัดลอกข้อความ
- ในตัวเล่นวิดีโอ กด Space เพื่อเล่น/หยุด ลูกศรเลื่อนครั้งละ 5 วินาที Page Up/Page Down ครั้งละ 30 วินาที

### การโทร
- เสียง NVDA ไม่เบาลงเมื่อ LINE ลดเสียงอื่นระหว่างโทร
- หน้าต่างวิดีโอคอลบอกว่ากล้องและไมโครโฟนเปิดอยู่หรือไม่ และ Alt+D วางสายวิดีโอคอลได้

## เวอร์ชัน 0.5.2
- กด Enter บนข้อความที่มีลิงก์เพื่อเปิดลิงก์ในเว็บเบราว์เซอร์
- ปุ่ม Applications บนข้อความเสียง ไฟล์ หรือรูป เปิดเมนูของข้อความนั้น
- กด Tab กลับเข้ารายการข้อความจะกลับไปที่ข้อความที่อ่านล่าสุด

- เข้าถึงช่องชื่อที่ตั้งให้เพื่อนได้ (โปรไฟล์ > แก้ไข)
- Alt+A / Alt+D ใช้ได้เมื่อ LINE หรือหน้าต่างโทรอยู่ด้านหน้า จากโปรแกรมอื่นใช้ NVDA+Shift+Control+A / D
