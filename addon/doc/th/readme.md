# LINE MR (ไลน์ไม่รู้) สำหรับ NVDA

LINE MR ทำให้ผู้ใช้ NVDA ใช้ [LINE บน Windows](https://line.me) ได้

LINE วาดปุ่มและข้อความเอง โปรแกรมอ่านหน้าจอจึงแทบไม่เห็นอะไรเลย ปุ่มไม่มีชื่อและอ่านข้อความไม่ได้ LINE MR เพิ่มตัวเชื่อมการเข้าถึงขนาดเล็กเข้าไปใน LINE เพื่อให้ปุ่มและข้อความมีชื่อ บทบาท และใช้งานได้ พร้อมโมดูลแอปของ NVDA ที่จัดการสิ่งที่ NVDA อ่านให้เรียบร้อย

## การติดตั้ง

**แนะนำ: ติดตั้ง [LINE จาก Microsoft Store](https://apps.microsoft.com/detail/XPFCC4CD725961)** (LINE Desktop ของ LY Corporation หรือเปิดแอป Microsoft Store แล้วค้นหา "LINE") LINE MR พัฒนาและทดสอบกับ LINE รุ่นจาก Microsoft Store จึงทำงานเข้ากันได้มากที่สุด รุ่นนี้ติดตั้ง LINE ไว้ที่ `%LOCALAPPDATA%\LINE` และอัปเดตให้อัตโนมัติ หากใช้ LINE จากแหล่งอื่น อาจติดตั้งไว้ที่อื่นหรือเป็นรุ่นที่ต่างออกไป ทำให้ติดตั้งหรือใช้ตัวเชื่อมไม่ได้

1. ติดตั้งส่วนเสริมนี้แล้วเปิด NVDA ใหม่
2. เปิด LINE (หรือสลับไปที่ LINE) LINE MR จะถามว่าต้องการติดตั้งตัวเชื่อมใน LINE หรือไม่ ให้เลือก **ใช่** LINE จะปิดแล้วเปิดใหม่พร้อมตัวเชื่อม

หลัง LINE อัปเดต อาจต้องติดตั้งตัวเชื่อมใหม่ LINE MR จะตรวจพบและถามอีกครั้ง

## การอัปเดต LINE MR

เมื่อเปิด NVDA LINE MR จะตรวจหารุ่นใหม่บน GitHub ถ้ามี จะแสดงหน้าต่างให้เลือก **อัปเดตตอนนี้** **ไว้ทีหลัง** หรือ **ข้ามรุ่นนี้** เมื่อเลือกอัปเดตตอนนี้ LINE MR จะดาวน์โหลดรุ่นใหม่แล้วส่งให้ NVDA ติดตั้ง NVDA จะถามยืนยันการติดตั้ง แล้วถามให้เริ่ม NVDA ใหม่ หากต้องการปิดการตรวจหรือตรวจทันที ไปที่ เมนู NVDA, ค่าติดตั้ง, การตั้งค่า หมวด "LINE MR" คำสั่ง "ตรวจหา LINE MR รุ่นใหม่" ไม่มีปุ่มลัดตั้งต้น กำหนดปุ่มได้ที่ คำสั่งป้อนเข้า ถ้าติดตั้ง LINE MR จาก Add-on Store ของ NVDA ตัว Store จะแจ้งอัปเดตให้เอง และ LINE MR จะไม่ตรวจหารุ่นใหม่บน GitHub

หมวดเดียวกันมีปุ่ม **มีอะไรใหม่** แสดงการเปลี่ยนแปลงของแต่ละเวอร์ชันในหน้าต่างที่อ่านได้เหมือนหน้าเว็บ (กด H เพื่อไปเวอร์ชันถัดไป)

## ใช้ LINE โดยไม่มี LINE MR

หากต้องการใช้ LINE ตามปกติโดยไม่มีการปรับของ LINE MR (เช่น เพื่อเปรียบเทียบ หรือเมื่อการเข้าถึงของ LINE เองเพียงพอแล้ว): เมนู NVDA, ตั้งค่า (Preferences), การตั้งค่า (Settings), หมวด "LINE MR" ปุ่ม **การตั้งค่าขั้นสูง...** กลุ่ม "ตัวเชื่อม" ช่อง **ตัวเชื่อม** บอกว่าตัวเชื่อมทำงานอยู่หรือไม่ และปุ่มถัดไปจะเสนอสิ่งที่ตรงข้าม: **ตัดการเชื่อมต่อตัวเชื่อม** ลบตัวเชื่อมออกจาก LINE (รวมถึงหน้าต่างการโทรและตัวดูรูป) **เชื่อมต่อตัวเชื่อม** ติดตั้งกลับเข้าไป ทั้งสองอย่างจะปิด LINE แล้วเปิดใหม่ สายที่กำลังคุยอยู่จะถูกตัด ระหว่างที่ตัดการเชื่อมต่อ LINE MR จะไม่ถามให้ติดตั้งตัวเชื่อม และ NVDA+Shift+Control+L จะบอกว่าตัดการเชื่อมต่ออยู่

## ไฮไลต์โฟกัส

สำหรับผู้ใช้สายตาเลือนราง LINE MR วาดกรอบสีเหลืองขอบดำรอบตัวควบคุมที่โฟกัสอยู่ใน LINE หน้าต่างการโทร และหน้าต่างดูรูปภาพ คือปุ่ม ช่องข้อความ แชท ข้อความ หรือรายการเมนูที่ NVDA กำลังอ่าน กรอบเลื่อนตามแป้นพิมพ์ รวมถึงในรายการแชท รายการข้อความ และเมนู และจะซ่อนเมื่อโปรแกรมอื่นอยู่ด้านหน้า ปิดได้ที่ เมนู NVDA > ตั้งค่า (Preferences) > การตั้งค่า (Settings) หมวด "LINE MR" ส่วนสี (เหลือง ส้ม แดง เขียว น้ำเงิน ขาว) และความหนาอยู่ในปุ่ม **การตั้งค่าขั้นสูง...** ของหมวดนั้น LINE จะใช้ค่าใหม่ภายในหนึ่งวินาที แม้ NVDA ไม่ได้เปิดอยู่

## สิ่งที่ใช้ได้ตอนนี้

- หน้าต่างเข้าสู่ระบบ: ช่องอีเมลและรหัสผ่าน ปุ่มเข้าสู่ระบบ กล่องกาเครื่องหมาย "เข้าสู่ระบบอัตโนมัติ" คำแนะนำคิวอาร์โค้ด และปุ่มบนแถบชื่อเรื่องมีชื่อครบ
- ปุ่มที่มีแต่ไอคอนจะมีชื่อตามไอคอน เป็นภาษาเดียวกับที่ LINE ใช้ (ไทย อังกฤษ ญี่ปุ่น จีนตัวย่อ หรือจีนตัวเต็ม)
- แป้นพิมพ์: กด Tab และ Shift+Tab ไปถึงทุกปุ่ม กล่องกาเครื่องหมาย และลิงก์ตามลำดับการอ่าน (เนื้อหาของหน้าต่างก่อน ปุ่มบนแถบชื่อเรื่องอยู่ท้ายสุด) กด Space หรือ Enter เพื่อกดสิ่งที่โฟกัสอยู่ ปกติ LINE ให้ Tab ไปได้แค่ช่องข้อความ
- NVDA อ่านตามโฟกัสเมื่อเลื่อนไปมา (ปกติ LINE ปิดการแจ้งเหล่านี้ไว้ ตัวเชื่อมเปิดกลับมาให้)
- กล่องกาเครื่องหมายบอกสถานะและเปลี่ยนสถานะได้ ("กาเครื่องหมาย" / "ไม่ได้กาเครื่องหมาย")
- ข้อความที่คลิกได้ เช่น "เข้าสู่ระบบด้วยสมาร์ทโฟน >" เป็นลิงก์ เมื่อกดแล้วหน้าจอเปลี่ยน โฟกัสจะไปที่ช่องแรกของหน้าจอใหม่
- เมื่อเข้าหน้าต่างเข้าสู่ระบบ NVDA จะอ่านคำแนะนำ (เช่น วิธีสแกนคิวอาร์โค้ด) กด NVDA+B เพื่ออ่านอีกครั้ง
- ซ่อนหน้าต่างเงาของ LINE และกลุ่มจัดวางที่ไม่มีชื่อจากการนำทางวัตถุ
- หน้าต่างหลัก: แท็บด้านข้าง ปุ่มบนหัวแชท และปุ่มบนแถบพิมพ์ข้อความมีชื่อ รายการแชทอ่าน "เลือกอยู่" ก่อนชื่อของแชทที่เปิดอยู่ แล้วอ่านชื่อ "ปักหมุด" สำหรับแชทที่ปักหมุดไว้ "กลุ่ม" หรือ "โอเพนแชท" จำนวนสมาชิก ข้อความล่าสุด เวลา และจำนวนที่ยังไม่อ่าน รายชื่อเพื่อนอ่านชื่อ จำนวนสมาชิก และหมวดกลุ่ม
- รายการแชท: ลูกศรขึ้น/ลง Page Up/Page Down และ Home/End เลื่อนดูแชทได้เร็วโดยไม่เปิดแชท (การเปิดแชททำให้ LINE ค้างได้ถึงสองวินาที) กด Enter เพื่อเปิดแชทและไปที่ช่องพิมพ์ข้อความ แชททางขวาจะเปลี่ยนเมื่อกด Enter เท่านั้น Space ใช้แทน Enter ได้ ถ้าซ่อนห้องแชทไว้ (ปุ่มแสดงหรือซ่อนห้องแชท) Enter หรือ Space จะเปิดแชทเป็นหน้าต่างแยกเหมือนดับเบิลคลิก แล้วไปที่ช่องพิมพ์ข้อความ Shift+Enter เปิดแชทเป็นหน้าต่างใหม่ (เหมือน "เปิดในหน้าต่างใหม่" ในเมนูของแชท) แล้วไปที่ช่องพิมพ์ข้อความ
- ข้อความ: อ่านผู้ส่ง (หรือ "คุณ") ข้อความ เวลา และสถานะอ่านแล้ว ข้อความที่ไม่ใช่ตัวอักษรจะบอกประเภท ได้แก่ รูปภาพ อัลบั้มรูปภาพ วิดีโอ สติกเกอร์ อีโมจิ LINE ข้อความเสียง (พร้อมความยาว) ไฟล์ (พร้อมชื่อและขนาด) ตำแหน่งที่ตั้ง (พร้อมที่อยู่) รายชื่อติดต่อ (พร้อมชื่อ) และการโทร (พร้อมระยะเวลาหรือสถานะ) เมื่อเข้ารายการข้อความจะเริ่มที่ข้อความล่าสุด ถ้ากลับมาด้วย Tab ในแชทเดิม จะกลับไปที่ข้อความที่อ่านล่าสุด ส่วน Shift+Tab จากช่องพิมพ์ข้อความจะอยู่ตรงตำแหน่งที่แชทเลื่อนอยู่ (ข้อความที่อ่านล่าสุดถ้ายังเห็นบนจอ ไม่เช่นนั้นข้อความแรกบนจอ) และการเปิดแชทด้วย Enter จะคงตำแหน่งของ LINE ไว้ เช่น ข้อความแรกที่ยังไม่ได้อ่าน (Alt+M ไปที่ข้อความล่าสุดเสมอ) ลูกศรขึ้น/ลง เลื่อนทีละข้อความ Page Up/Page Down เลื่อนประมาณหนึ่งหน้าจอ Home ไปที่ข้อความเก่าสุดที่โหลดแล้ว (LINE โหลดข้อความเก่าเพิ่ม กด Home อีกครั้งเพื่อย้อนต่อ) End ไปที่ข้อความล่าสุด กด Home หรือ End ซ้ำเพื่ออ่านข้อความนั้นอีกครั้ง ข้อความใหม่จากผู้อื่นจะถูกอ่านเมื่อ LINE อยู่หน้าสุด ในแชทหนึ่งต่อหนึ่ง ให้อ่านชื่ออีกฝ่ายก่อนข้อความที่ได้รับได้ โดยเปิด "แสดงชื่อผู้ส่งในแชทหนึ่งต่อหนึ่ง" ในการตั้งค่า NVDA หมวด LINE MR (ปิดไว้เป็นค่าเริ่มต้น) ถ้าต้องการให้อ่านชื่อผู้ส่งเฉพาะเมื่อผู้ส่งเปลี่ยน ไม่อ่านซ้ำทุกข้อความที่คนเดิมส่งต่อกัน ให้เปิด "อ่านชื่อผู้ส่งเฉพาะเมื่อผู้ส่งเปลี่ยน" ในหมวดเดียวกัน
- ลำดับ Tab ในแผงรายการแชท: เรียงลำดับ ซ่อนหน้าต่างห้องแชท / แสดงหน้าต่างห้องแชท (ชื่อตาม LINE: ซ่อนหรือแสดงแชทที่เปิดอยู่ทางขวา ถ้าซ่อน หน้าต่างจะแคบลงเหลือแค่รายการแชท) สร้างแชท โฆษณา ช่องค้นหา แล้วจึงเป็นรายการแชท (กด Tab ต่อไปที่แชทที่เปิดอยู่)
- เรียงลำดับ (ข้างช่องค้นหาของรายการแชท): ตัวเลือกบอกว่าเลือกอันไหนอยู่ (เวลาที่ได้รับ หรือ ยังไม่ได้อ่าน) เมื่อเลือกแล้วโฟกัสจะไปที่แชทแรกของรายการที่เรียงใหม่ หากเลือก ยังไม่ได้อ่าน แชทที่มีข้อความยังไม่อ่านจะขึ้นก่อน ส่วนบนของรายการจึงอาจดูเหมือนเดิมเมื่อแชทล่าสุดของคุณยังไม่ได้อ่านอยู่แล้ว
- ค้นหาในแชท (ปุ่มค้นหาที่หัวแชท): พิมพ์คำแล้วกด Enter LINE ไม่ได้กรองข้อความ แต่จะเลื่อนแชทไปที่ข้อความล่าสุดที่ตรงกันและแสดงจำนวนผลการค้นหา LINE MR จะอ่าน "ผลการค้นหา 42 จาก 42" และข้อความนั้น ลูกศรขึ้น/ลงในช่องค้นหา (หรือปุ่ม ผลการค้นหาก่อนหน้า / ผลการค้นหาถัดไป) ไปยังผลที่เก่ากว่า / ใหม่กว่า กด Enter เพื่อเริ่มใหม่จากผลล่าสุด กด Alt+M หรือ Tab เข้ารายการข้อความจะอยู่ที่ข้อความที่พบ จึงอ่านข้อความรอบ ๆ ได้ ปุ่ม "แสดงผลการค้นหาเป็นรายการ" เปิดผลทั้งหมดในหน้าต่างแยก (ผู้ส่ง วันที่ ข้อความ) กด Enter บนผลใดจะไปที่ข้อความนั้นในแชท ปุ่ม "ไปยังวันที่" เปิดปฏิทิน
- ลำดับ Tab ในแชทที่เปิดอยู่: ปุ่มบนหัวแชท โน้ตของแชท (ถ้ามี) "เลื่อนไปข้อความล่าสุด" รายการข้อความ ช่องพิมพ์ข้อความ แล้วตามด้วยปุ่มบนแถบพิมพ์ข้อความจากช่องพิมพ์ออกไป (สติกเกอร์และอีโมจิ ตัวเลือกการจับภาพหน้าจอ จับภาพหน้าจอ Keep แนบไฟล์)
- เมนูบริบท: ปุ่ม Applications (หรือ Shift+F10) บนข้อความเปิดเมนูของ LINE โฟกัสไปที่รายการแรก ลูกศรขึ้น/ลง Home/End เลื่อนในเมนู Enter หรือ Space เลือก Escape ปิดเมนูและกลับไปที่ข้อความ บนข้อความที่คนอื่นส่งมาในกลุ่มหรือโอเพนแชท รายการสุดท้าย "แสดงโปรไฟล์ <ชื่อ>" จะเปิดโปรไฟล์ของผู้ส่ง (LINE MR เพิ่มรายการนี้ให้ ไม่แสดงบนหน้าจอ) บนข้อความ (ไม่รวมวันที่ ข้อความแจ้งของระบบ และการโทร) รายการ "แสดงความรู้สึก" (LINE MR เพิ่มให้เช่นกัน อยู่ก่อนรายการโปรไฟล์) จะเปิดแถบแสดงความรู้สึกของ LINE ลูกศรซ้าย/ขวาเลื่อนระหว่าง สุดยอด ถูกใจ ตลก อิจฉา เศร้า และความรู้สึกเพิ่มเติม (ชื่อตรงกับ LINE บนมือถือ และ LINE อาจสลับลำดับ) Enter เลือก Escape ปิดแถบ ความรู้สึกที่เคยเลือกไว้จะอ่านว่า "เลือกอยู่" และเลือกซ้ำเพื่อยกเลิกได้ บนข้อความที่คุณเคยแสดงความรู้สึกแล้ว รายการในเมนูจะเป็น "ยกเลิกการแสดงความรู้สึก" ซึ่งยกเลิกให้ทันที ข้อความที่มีคนแสดงความรู้สึกจะบอกว่าเป็นความรู้สึกอะไร เช่น "ความรู้สึก: ถูกใจ", "ถูกใจ 3 คน" หรือ "ความรู้สึก: ถูกใจ, ตลก, รวม 5 คน" (LINE แสดงแค่จำนวนรวม ไม่แยกตามความรู้สึก) ข้อความใน Keep Memo แสดงความรู้สึกไม่ได้ การเลือก "ตอบกลับ" จะย้ายไปที่ช่องพิมพ์ข้อความ ระหว่างตอบกลับ กด Shift+Tab จากช่องพิมพ์ข้อความจะไปที่ "ยกเลิกการตอบกลับ" แล้ว "ไปที่ข้อความต้นฉบับ" (เลื่อนแชทไปที่ข้อความนั้น) กด Escape ในช่องพิมพ์ข้อความก็ยกเลิกการตอบกลับได้
- สายเรียกเข้า: LINE MR จะพูดว่า "สายเรียกเข้า" พร้อมชื่อผู้โทร แม้กำลังใช้โปรแกรมอื่นอยู่ เมื่อหน้าต่างของ LINE อยู่ด้านหน้า กด Alt+A เพื่อรับสาย หรือ Alt+D เพื่อปฏิเสธสาย ถ้าอยู่ในโปรแกรมอื่น กด NVDA+Shift+Control+A หรือ NVDA+Shift+Control+D (Alt+A และ Alt+D ทำงานตามปกติของโปรแกรมนั้น) ระหว่างการโทร กด Alt+D ใน LINE หรือ NVDA+Shift+Control+D จากทุกโปรแกรมเพื่อวางสาย ถ้าไม่มีสาย LINE เรียกเข้า Alt+A และ Alt+D ทำงานตามปกติของ LINE โฟกัสจะไปที่ปุ่มรับสายในหน้าต่างสายเรียกเข้า (กด Tab ไปที่ปุ่มปฏิเสธสาย กด Enter หรือ Space เพื่อกด) ระหว่างการโทร ปุ่มในหน้าต่างการโทรมีชื่อครบ (วางสาย ปิดไมโครโฟน เริ่มวิดีโอคอล ปิดเสียง) และอ่านข้อความในหน้าต่างได้ (ชื่อผู้โทร ระยะเวลาการโทร) ระหว่างการโทร Windows จะลดเสียงอื่น ๆ ลง (แผงควบคุมเสียง แท็บการสื่อสาร) LINE MR ทำให้เสียงพูดของ NVDA ดังเท่าเดิม (มีผลกับการโทรในโปรแกรมอื่นด้วย)
- หน้าที่เปิดเป็นหน้าต่างใหม่อ่านได้แล้ว: กดชื่อกลุ่มหรือจำนวนสมาชิก (เช่น "(5)") จะเปิดรายชื่อสมาชิก กดสมาชิกจะเปิดโปรไฟล์ เมนูของแชท รูป & วิดีโอ ลิงก์ และไฟล์ เปิดหน้าต่างที่ใช้ชื่อแชท ในหน้าต่างนั้นใช้ลูกศรเลื่อนในตารางรูป วิดีโอ และลิงก์ได้ (ซ้าย/ขวาทีละรายการ ขึ้น/ลงทีละแถว) รวมถึง Page Up/Page Down, Home และ End รูปหรือวิดีโอแต่ละรายการอ่านว่า "รูปภาพ" หรือ "วิดีโอ" กด Enter เพื่อเปิดในตัวดูของ LINE (ลิงก์และไฟล์ใช้ Space ได้ด้วย ลิงก์จะเปิดในเบราว์เซอร์) หากต้องการบันทึกหรือแชร์รูปและวิดีโอหลายรายการพร้อมกัน ให้กด Space เพื่อเลือกทีละรายการ NVDA จะบอกว่าแต่ละรายการถูกเลือกไว้หรือไม่ และ LINE จะแสดงแถบใต้ตาราง ("เลือก 2 รายการ", แชร์, ส่งไปยัง Keep Memo, ดาวน์โหลด, ยกเลิก) ซึ่งไปถึงได้ด้วย Tab ปุ่มดาวน์โหลดจะถามโฟลเดอร์ผ่านกล่องโต้ตอบของ Windows ส่วนยกเลิกจะยกเลิกการเลือกทั้งหมดและกลับไปที่ตาราง รูปในอัลบั้มที่ส่งมาในแชทก็อยู่ในตารางนี้เช่นกัน ปุ่ม Applications เปิดเมนูที่ LINE MR เพิ่มให้: เปิด, บันทึก (รูป วิดีโอ และไฟล์ แล้ว LINE จะถามโฟลเดอร์หรือชื่อไฟล์ในหน้าต่างของ Windows), คัดลอกลิงก์ และคัดลอกข้อความ (ลิงก์) ในตัวเล่นวิดีโอของ LINE มีปุ่มเล่น/หยุดชั่วคราว และแถบตำแหน่ง: Tab สลับระหว่างสองอย่างนี้ Space หรือ Enter เล่นหรือหยุด ลูกศรเลื่อนทีละ 5 วินาที Page Up/Page Down ทีละ 30 วินาที Home/End ไปต้น/ท้าย และอ่านตำแหน่งแบบ "00:12 / 00:38" ตัวควบคุมที่สามคือความเร็วในการเล่น ("1.0x" ตั้งแต่ 0.2x ถึง 2.0x) ปรับด้วยลูกศรขึ้น/ลง ปุ่มเหล่านี้ใช้ได้แม้ LINE จะใช้ลูกศรขวาเพื่อไปรูปหรือวิดีโอถัดไป แถบรูปย่อด้านล่างอ่านว่ารูปภาพหรือวิดีโอ โน้ต (ปุ่มโน้ตในกลุ่มหรือโอเพนแชท): ลูกศร Home และ End เลื่อนทีละโพสต์ แต่ละโพสต์อ่านแบบ "Peet, วิดีโอ, ความคิดเห็น 2 รายการ, 8 นาทีที่ผ่านมา" กด Enter หรือ Space เพื่อเปิดรูปหรือวิดีโอของโพสต์ในตัวดูเดียวกัน โฟกัสเริ่มที่ปุ่มเล่น/หยุดชั่วคราวของตัวเล่น และ Escape กลับไปที่โพสต์เดิม ปุ่ม Applications บนโพสต์เปิดเมนู: เปิด, บันทึกเป็น... (ตัวดูของ LINE เปิดขึ้นและ Windows ถามว่าจะบันทึกที่ไหน), คัดลอกข้อความ (โพสต์ที่มีข้อความ) และตัวเลือกเพิ่มเติม (เมนูของ LINE: กำหนดเป็นโน้ตสำคัญ แก้ไข ลบ) ในตัวดู กด Ctrl+S เพื่อบันทึกได้เช่นกัน โฟกัสเริ่มที่ตัวควบคุมแรกของหน้านั้นและอ่านข้อความในหน้า หน้าที่เปิดในหน้าต่างหลักก็ได้รับโฟกัสเช่นกัน
- สติกเกอร์และอีโมจิ (ปุ่มในแถบพิมพ์ข้อความ): แถบแพ็กเกจอ่านว่า "ใช้ล่าสุด" และชื่อแพ็กเกจ (LINE ให้แถบนี้เป็นรูปอย่างเดียว ชื่อจึงอ่านมาจากหน้า "สติกเกอร์ของฉัน" ที่ปุ่มแก้ไขของหน้าสติกเกอร์ เมื่อยังไม่มีชื่อหรือจำนวนแพ็กเกจเปลี่ยน LINE MR จะเปิดหน้านั้นเองประมาณหนึ่งวินาทีตอนเปิดหน้าสติกเกอร์ แล้วกลับมาที่หน้าเดิม) ใช้ลูกศรซ้าย/ขวาเลื่อน และ Enter เปิดแพ็กเกจแล้วไปที่สติกเกอร์แรก สติกเกอร์อ่านว่า "สติกเกอร์ 1", ... (LINE ไม่มีชื่อสติกเกอร์ให้) ใช้ลูกศรเลื่อนในตาราง กด Enter หรือ Space ครั้งแรกเพื่อเลือกสติกเกอร์หรืออีโมจิ ("เลือกอยู่, กดอีกครั้งเพื่อส่ง") และเล่นตัวอย่างของ LINE พร้อมเสียง (สติกเกอร์ที่มีเสียง) กดอีกครั้งเพื่อส่ง แล้วหน้าสติกเกอร์จะปิดและกลับไปที่ช่องพิมพ์ข้อความ ปุ่มลูกศรลงกลม ๆ ที่ขึ้นเมื่อเลื่อนแชทขึ้นไป อ่านว่า "เลื่อนไปข้อความล่าสุด"
- หน้าต่างอื่น ๆ: การตั้งค่า (เพิ่มเติม > ตั้งค่า หมวดและหมวดย่อยเป็นปุ่มตัวเลือก กล่องรายการมีชื่อตามหัวข้อ) ตั้งค่าโปรไฟล์ อัลบั้มและโน้ต ค้นหาเพื่อน และสร้างแชท (ปุ่มใต้รายการแชท: แชท กลุ่มแชท โอเพนแชท) ในรายชื่อเพื่อนของสร้างแชท / สร้างกลุ่ม เพื่อนแต่ละคนเป็นกล่องกาเครื่องหมาย ลูกศรขึ้น/ลง Page Up/Page Down และ Home/End เลื่อนไปได้ทั้งรายชื่อ กด Space เพื่อเลือก กด Tab เพื่อออกจากรายชื่อไปที่เพื่อนที่เลือกไว้ ("นำ <ชื่อ> ออก") และปุ่มต่อไป กด Shift+Tab กลับไปที่เพื่อนคนล่าสุดที่อ่าน หน้าตั้งค่าโปรไฟล์กลุ่มมีปุ่มเปลี่ยนรูปโปรไฟล์ แก้ไขชื่อกลุ่ม และสวิตช์ "สมาชิกเข้าร่วมกลุ่มโดยอัตโนมัติ" (เป็นกล่องกาเครื่องหมาย) สร้างโอเพนแชทถามชื่อโอเพนแชท คีย์เวิร์ด และหมวดหมู่ก่อน แล้ว (หลังกดต่อไป) ถามชื่อเล่นของคุณในโอเพนแชทนั้น ช่องข้อความจะอ่านคำอธิบายว่าหน้านี้ใช้ทำอะไร ปุ่ม X ในช่องคือ "ล้างข้อความ" เปลี่ยนรูปโปรไฟล์ > สร้างโปรไฟล์ข้อความ: สีแต่ละสีเป็นกล่องกาเครื่องหมาย มีหมายเลขและชื่อสี ("สี 4: ชมพูอ่อน") กด Space เพื่อเลือก (เลือกแล้ว) ปุ่มสีตัวอักษร / สีพื้นหลังเลือกว่าจะเปลี่ยนสีของอะไร กล่องรายการฟอนต์ชื่อ "ฟอนต์" โหวตเปิดเป็นหน้าเว็บ อ่านด้วยโหมดเรียกดู
- ข้อความแบบรูปภาพ (การ์ดจากบัญชีทางการ เช่น ธนาคาร) เป็นรูปที่มีตัวอักษรอยู่ในรูป LINE จึงไม่มีข้อความให้อ่าน จะอ่านว่า "รูปภาพหรือสติกเกอร์" กด NVDA+R บนข้อความนั้นเพื่ออ่านตัวอักษรด้วย OCR ของ Windows ถ้า LINE ดาวน์โหลดการ์ดไม่ได้ จะแสดง "ไม่สามารถโหลดได้" และปุ่ม "ลองอีกครั้ง" ซึ่งเป็นสิ่งที่ได้ยิน

## แปลงข้อความเสียงเป็นข้อความ

ปิดไว้เป็นค่าเริ่มต้น ถ้าจะเปิด ให้ไปที่การตั้งค่า NVDA หมวด LINE MR กลุ่ม "แปลงข้อความเสียงเป็นข้อความ" เลือก "แปลงข้อความเสียงเป็นข้อความด้วย Alt+Shift+T" แล้วกดตกลง (โมเดลเสียง ไฟล์โมเดลของคุณเอง และภาษาเริ่มต้นอยู่ในปุ่ม **การตั้งค่าขั้นสูง...**) LINE MR จะดาวน์โหลดโปรแกรมรู้จำเสียง whisper.cpp (5 MB) และโมเดลที่เลือกครั้งเดียว แล้วแจ้งเมื่อพร้อมใช้งาน ช่อง "สถานะโมเดล" บอกโมเดลที่เลือกและบอกว่าดาวน์โหลดไปถึงไหนแล้ว ถ้าการดาวน์โหลดถูกขัดจังหวะหรือไม่สำเร็จ จะดาวน์โหลดต่อเมื่อเปิด NVDA ครั้งถัดไป หรือเมื่อกด Alt+Shift+T บนข้อความเสียง เมื่อยกเลิกการเลือก จะถามว่าต้องการลบไฟล์ที่ดาวน์โหลดไว้หรือไม่ และเมื่อเปลี่ยนไปใช้โมเดลอื่น จะถามว่าต้องการลบโมเดลเดิมหรือไม่

โมเดลเสียง (Typhoon ของ SCB 10X คือ Whisper ที่ฝึกเพิ่มด้วยภาษาไทย ส่วน Whisper ของ OpenAI รู้หลายภาษา หน่วยความจำคือขณะแปลง วัดบนโน้ตบุ๊ก i5-1235U): รายการนี้มาจาก repository ของ LINE MR บน GitHub และจะดึงใหม่ทุกครั้งที่เปิดการตั้งค่าหรือหน้าต่างก่อนแปลง โมเดลใหม่จึงขึ้นมาให้เลือกได้โดยไม่ต้องอัปเดต add-on

- Typhoon Whisper Turbo (874 MB ค่าเริ่มต้น): เหมาะกับภาษาไทยที่สุด ใช้กับภาษาอังกฤษและญี่ปุ่นได้ด้วย และใช้หน่วยความจำน้อยที่สุดในกลุ่ม Typhoon (ราว 1.1 GB)
- Typhoon Whisper Medium (823 MB): ภาษาไทยเท่านั้น (ภาษาอังกฤษ ญี่ปุ่น และจีนจะออกมาเป็นตัวอักษรไทย) เร็วเท่า Turbo กับภาษาไทย แต่ใช้หน่วยความจำราว 1.5 GB
- Typhoon Whisper Large v3 (1,081 MB): ภาษาไทยเท่านั้น (เหมือน Medium) และแม่นยำกับภาษาไทยที่สุด แต่ช้ามาก (ข้อความยาว 36 วินาทีใช้เกือบ 10 นาที ส่วน Turbo ใช้ 1 นาทีครึ่ง) และใช้หน่วยความจำราว 2 GB
- Whisper Small (264 MB): เล็กและเร็ว รู้หลายภาษา แต่ภาษาไทยผิดมาก
- Whisper Medium (823 MB) และ Whisper Large v3 Turbo (874 MB): รู้หลายภาษา ไม่ได้ฝึกเพิ่มด้วยภาษาไทย
- "เลือกไฟล์โมเดลเอง": โมเดล whisper.cpp ที่คุณดาวน์โหลดมาเอง (ไฟล์ ggml .bin เช่นจาก huggingface.co/ggerganov/whisper.cpp) LINE MR จะตรวจว่าเป็นโมเดลของ whisper.cpp และไฟล์ครบ แล้วให้โปรแกรมรู้จำเสียงลองโหลดหนึ่งครั้งก่อนใช้ รูปแบบอื่น (.pt, .safetensors, GGUF, ONNX, faster-whisper) ต้องแปลงก่อน และโมเดลภาษาอังกฤษอย่างเดียว (ชื่อลงท้ายด้วย .en) แปลงภาษาอื่นไม่ได้

จากนั้นบนข้อความเสียง กด Alt+Shift+T หรือเลือก "แปลงเสียงเป็นข้อความ" ในเมนูของข้อความ (ปุ่ม Applications) จะมีหน้าต่างถามโมเดลเสียง (โมเดลที่เลือกตรงนี้จะใช้ต่อในครั้งถัดไป ถ้ายังไม่ได้ดาวน์โหลดจะดาวน์โหลดให้ แล้วกด Alt+Shift+T อีกครั้ง) และภาษาของข้อความเสียง (ค่าเริ่มต้นคือ "ตรวจหาอัตโนมัติ" ถ้าเลือกภาษาเองจะเร็วและแม่นกว่า และภาษาจีนบางครั้งถูกตรวจเป็นภาษาไทย) เลือก "ไม่ต้องแสดงหน้านี้อีก" เพื่อข้ามหน้าต่างนี้ โมเดล ภาษา และการถามนี้ตั้งค่าได้ในการตั้งค่าด้วย หลังกดตกลง จะมีหน้าต่างแสดงสถานะพร้อมแถบความคืบหน้า: กำลังดึงข้อความเสียงจาก LINE (LINE จะบันทึกไฟล์ของข้อความที่เลือกลงโฟลเดอร์ของ LINE MR (%LOCALAPPDATA%\LineMR\media) และลบไฟล์ทิ้งเมื่อได้ข้อความแล้ว หน้าต่างบันทึกเป็นจะขึ้นมาครู่หนึ่งและ LINE MR กรอกให้ ถ้า LINE บันทึกไม่ได้จะเล่นข้อความแล้วอัดเสียงแทน) แล้วกำลังแปลงเป็นข้อความพร้อมเปอร์เซ็นต์โดยประมาณ (LINE MR เรียนรู้ความเร็วของเครื่องนี้) เมื่อเสร็จ ข้อความจะแสดงในหน้าต่างเดิมในช่องที่แก้ไขได้ พร้อมปุ่มคัดลอก (คัดลอกข้อความตามที่แก้ไขแล้ว) และปิด (Escape) ข้อความอาจมีคำผิด ระหว่างทำงาน กดยกเลิกหรือ Escape ในหน้าต่าง หรือ Alt+Shift+T ใน LINE เพื่อยกเลิก

ข้อความจะขึ้นระหว่างที่แปลง ทุก ๆ 30 วินาทีของเสียง บรรทัดใหม่จะถูกเติมต่อท้ายช่องข้อความ อ่านและแก้ไขข้อความไปพร้อมกันได้ บรรทัดที่เติมเข้ามาจะไม่ย้ายเคอร์เซอร์หรือส่วนที่เลือกไว้ และเมื่อแปลงเสร็จจะไม่เขียนทับสิ่งที่แก้ไว้ ปุ่มคัดลอกจะขึ้นเมื่อแปลงเสร็จ เสียงที่ยาวกว่า 30 วินาทีจะถูกตัดตรงช่วงที่หยุดพูดเป็นท่อนละไม่เกิน 30 วินาทีก่อน (ตัวรู้จำเสียงฟังทีละ 30 วินาที และอาจพูดคำซ้ำหรือทำคำหายตรงรอยต่อ)

ไม่มีการเล่นเสียงและไม่มีการส่งอะไรขึ้นอินเทอร์เน็ต: LINE เก็บข้อความเสียงทุกข้อความที่เคยเล่นหรือดาวน์โหลดไว้ในเครื่อง และ LINE MR แปลงจากไฟล์นั้นบนเครื่องนี้ ข้อความเสียงที่ยังไม่เคยเล่นจะยังไม่มีไฟล์ กรณีนี้ LINE จะเล่นข้อความหนึ่งครั้ง (จะได้ยินเสียง) และ LINE MR ใช้ไฟล์ทันทีที่ LINE ดาวน์โหลดเสร็จ เครื่องที่ช้าจะใช้เวลาแปลงพอสมควร (โน้ตบุ๊ก i5-1235U กับ Typhoon Whisper Turbo ใช้ราว 20 วินาทีกับข้อความยาว 7 วินาที และ 1 นาทีครึ่งกับข้อความยาว 36 วินาที) ต้องใช้ Windows 10 รุ่น 2004 ขึ้นไปแบบ 64 บิต

วิดีโอก็ได้: กด Alt+Shift+T บนวิดีโอในแชท (หรือเลือก "ถอดเสียงวิดีโอเป็นข้อความ" ในเมนูของวิดีโอ) บนวิดีโอในหน้าต่างรูปและวิดีโอ บนโพสต์ที่มีวิดีโอในโน้ต (LINE MR จะเปิดวิดีโอในโปรแกรมดูของ LINE แล้วหยุดเล่นไว้) หรือในโปรแกรมดูของ LINE ขณะแสดงวิดีโอ LINE MR จะให้ LINE บันทึกวิดีโอลงโฟลเดอร์ของ LINE MR (หน้าต่างบันทึกเป็นของ LINE จะขึ้นมาครู่หนึ่งและ LINE MR กรอกให้) แล้วแปลงเสียงของวิดีโอ และลบไฟล์นั้นเมื่อเสร็จ ถ้าข้อความเสียงหรือวิดีโอยาวเกิน 5 นาที LINE MR จะแจ้งก่อนว่าการแปลงทำบนเครื่องนี้และอาจใช้เวลานาน (พร้อมเวลาโดยประมาณ) ให้เลือกตกลงหรือยกเลิก วิดีโอที่แชร์เป็นลิงก์ (YouTube, Facebook) ถอดเสียงไม่ได้ เพราะไม่ได้เล่นใน LINE

## ดาวน์โหลดจาก YouTube

บนข้อความที่มีลิงก์ YouTube (วิดีโอ, Shorts หรือเพลย์ลิสต์) กด Alt+Shift+Y หรือเลือก "ดาวน์โหลดวิดีโอจาก YouTube" ในเมนูของข้อความ (ปุ่ม Applications) ก่อนดาวน์โหลดจะมีคำเตือนให้ดาวน์โหลดเฉพาะวิดีโอที่คุณมีสิทธิ์ (ข้อกำหนดในการให้บริการของ YouTube ไม่อนุญาตอย่างอื่น) ติ๊ก "ไม่ต้องแสดงอีก" เพื่อข้ามคำเตือน (เปิดกลับได้ในการตั้งค่า)

ครั้งแรก LINE MR จะดาวน์โหลดโมดูลดาวน์โหลด YouTube (ประมาณ 130 MB ประกอบด้วยโปรแกรมโอเพนซอร์ส yt-dlp, Deno และ FFmpeg) ไว้ที่ %LOCALAPPDATA%\LineMR\youtube โมดูลนี้อัปเดตแยกจาก LINE MR: ก่อนดาวน์โหลด (ไม่เกินทุก 3 ชั่วโมง) LINE MR จะตรวจหาโมดูลรุ่นใหม่และอัปเดตเฉพาะส่วนที่เปลี่ยน (ส่วนใหญ่เป็น yt-dlp ประมาณ 23 MB) จึงยังดาวน์โหลดได้เมื่อ YouTube เปลี่ยนแปลง ถ้าไม่มีอินเทอร์เน็ตจะใช้โมดูลที่ดาวน์โหลดไว้แล้ว

จากนั้นหน้าต่างจะตรวจสอบลิงก์ (ถ้าวิดีโอเป็นแบบส่วนตัว ถูกลบ จำกัดอายุ ถูกบล็อกในประเทศของคุณ หรือเป็นไลฟ์สด NVDA จะบอกเหตุผล) แล้วให้เลือก: ถ้าลิงก์เป็นวิดีโอในเพลย์ลิสต์ เลือกได้ว่าเฉพาะวิดีโอนี้หรือทั้งเพลย์ลิสต์ (พร้อมจำนวนวิดีโอ) รูปแบบ วิดีโอ (MP4) หรือเสียงอย่างเดียว (MP3) คุณภาพ (ความละเอียดที่วิดีโอนั้นมี พร้อมขนาดไฟล์ถ้า YouTube บอก ส่วน MP3 เลือก 128, 192 หรือ 320 kbps) และโฟลเดอร์ (โฟลเดอร์ Downloads ถ้าไม่ได้เลือกที่อื่น LINE MR จำตัวเลือกไว้) ปุ่มดาวน์โหลดจะแสดงความคืบหน้าพร้อมเสียงบี๊ปที่สูงขึ้น (เพลย์ลิสต์: "กำลังดาวน์โหลดวิดีโอที่ 2 จาก 13") ยกเลิกหรือ Escape จะหยุดและลบไฟล์ที่ดาวน์โหลดค้างไว้ เมื่อเสร็จ ปุ่มเปิดโฟลเดอร์จะแสดงไฟล์ เพลย์ลิสต์จะอยู่ในโฟลเดอร์ชื่อเดียวกับเพลย์ลิสต์ วิดีโอเรียงเลขตามลำดับ วิดีโอที่ดาวน์โหลดไม่ได้จะถูกข้ามและนับจำนวนให้

ในการตั้งค่า NVDA หมวด LINE MR กลุ่ม "ดาวน์โหลดจาก YouTube": ปิดรายการในเมนูและ Alt+Shift+Y ส่วนในปุ่ม **การตั้งค่าขั้นสูง...**: แสดงคำเตือนอีกครั้ง ดูรุ่นของโมดูล หรือลบโมดูล

## คำสั่ง

| คำสั่ง | การทำงาน |
|---|---|
| Alt+1 / Alt+2 / Alt+3 | แท็บเพื่อน / แชท / เพิ่มเพื่อน |
| Alt+C | ไปที่รายการแชท (สลับไปที่แท็บแชทก่อนถ้าจำเป็น) ใช้จากแชทที่เปิดเป็นหน้าต่างแยกได้ด้วย โดยจะพาหน้าต่างหลักของ LINE ขึ้นมาก่อน |
| Alt+L | ไปที่รายการแชทหรือรายชื่อเพื่อน (รายการที่แสดงอยู่) |
| Alt+F | ไปที่ช่องค้นหาของรายการแชทหรือรายชื่อเพื่อน |
| Alt+M | ไปที่ข้อความของแชทที่เปิดอยู่ ถ้าอยู่ในหน้าต่างหลักที่ซ่อนห้องแชทไว้ จะไปที่แชทที่เปิดเป็นหน้าต่างแยก |
| Alt+I | ไปที่ช่องพิมพ์ข้อความ ถ้าอยู่ในหน้าต่างหลักที่ซ่อนห้องแชทไว้ จะไปที่แชทที่เปิดเป็นหน้าต่างแยก |
| Alt+R | ในรายการข้อความ: ตอบกลับข้อความที่เลือก แล้วไปที่ช่องพิมพ์ข้อความ |
| Alt+Shift+R | ในรายการข้อความ: เปิดการแสดงความรู้สึกของข้อความที่เลือก (ลูกศรซ้าย / ขวา เลือก, Enter ใส่หรือเอาออก) |
| Delete | ในรายการข้อความ: ลบข้อความที่เลือก (เหมือน "ลบ" ในเมนูของข้อความ LINE ลบเฉพาะในเครื่องนี้) |
| Shift+Delete | ในรายการข้อความ: ยกเลิกข้อความที่เลือก (เหมือน "ยกเลิกข้อความ" ในเมนูของข้อความ) |
| Alt+T | ในรายการข้อความ: แปลข้อความที่เลือก (เหมือนเลือก "แปล" ในเมนูของข้อความ) |
| Alt+Shift+T | ในรายการข้อความ: แปลงข้อความเสียงที่เลือกเป็นข้อความ (ต้องเปิดในการตั้งค่าก่อน กดอีกครั้ง: ยกเลิก) รวมถึงวิดีโอในแชท ในหน้าต่างรูปและวิดีโอ ในโน้ต หรือในโปรแกรมดูของ LINE |
| Ctrl+S | ในรายการข้อความ: บันทึกข้อความที่เลือก รูป วิดีโอ ไฟล์ และข้อความเสียง: ใช้คำสั่งบันทึกเป็นของ LINE (LINE ถามที่เก็บ) ข้อความตัวอักษร ตำแหน่ง และรายชื่อติดต่อ: บันทึกเป็นไฟล์ข้อความ (.txt, LINE MR ถามที่เก็บ) สติกเกอร์ การโทร วันที่ และข้อความแจ้งเตือนในแชทบันทึกไม่ได้ |
| Alt+Shift+Y | ในรายการข้อความ: ดาวน์โหลดวิดีโอจากลิงก์ YouTube ในข้อความที่เลือก เป็น MP4 หรือ MP3 รวมทั้งทั้งเพลย์ลิสต์ (ดู "ดาวน์โหลดจาก YouTube") |
| NVDA+Alt+1 … NVDA+Alt+9 | อ่านข้อความล่าสุด (1 = ใหม่สุด) |
| Alt+A ใน LINE, NVDA+Shift+Control+A จากทุกโปรแกรม | รับสายเรียกเข้าของ LINE |
| Alt+D ใน LINE, NVDA+Shift+Control+D จากทุกโปรแกรม | ปฏิเสธสายเรียกเข้าของ LINE ระหว่างการโทรใช้วางสาย |
| NVDA+Shift+Control+L | บอกว่าตัวเชื่อม LINE MR ทำงานอยู่หรือไม่ (และเสนอให้ติดตั้ง) กดสองครั้งเพื่อคัดลอกรายงานสำหรับผู้พัฒนาไปยังคลิปบอร์ด |

เปลี่ยนคำสั่งได้ที่ เมนู NVDA, ค่าติดตั้ง, คำสั่งป้อนเข้า หมวด "LINE MR" Alt+R, Delete, Shift+Delete, Alt+T และ Ctrl+S ทำงานเฉพาะในรายการข้อความ ที่อื่น (เช่น ช่องพิมพ์ข้อความ) ปุ่มทำงานตามปกติ คำสั่งเหล่านี้เลือกรายการของ LINE เองในเมนูของข้อความ ถ้าข้อความนั้นไม่มีรายการนี้ (เช่น ตอบกลับและแสดงความรู้สึกใน Keep Memo หรือยกเลิกข้อความของคนอื่น) NVDA จะบอกว่าใช้ไม่ได้ Ctrl+S บันทึกข้อความตัวอักษรได้ครบ แม้ข้อความยาว: LINE MR ใช้คำสั่งคัดลอกของ LINE แล้วคืนสิ่งที่อยู่ในคลิปบอร์ดเดิมกลับ (ประวัติคลิปบอร์ดของ Windows หรือ Windows+V จะยังเก็บข้อความนั้นไว้) คำสั่งที่ใช้ตัวอักษรหรือตัวเลข (Alt+C, Alt+1, Alt+Shift+R ...) ใช้ได้แม้แป้นพิมพ์อยู่ภาษาไทยหรือภาษาอื่นที่ไม่ใช่อักษรละติน โดยนับตามตำแหน่งปุ่มเดียวกับแป้นภาษาอังกฤษ

### ปุ่มที่ใช้ใน LINE

| ที่ไหน | ปุ่ม |
|---|---|
| ทุกที่ | Tab / Shift+Tab ไปยังตัวควบคุมถัดไป / ก่อนหน้า Space หรือ Enter กดปุ่ม กล่องกาเครื่องหมาย และลิงก์ |
| รายการแชท | ลูกศรขึ้น/ลง Page Up/Page Down Home/End เลื่อนดูแชทโดยไม่เปิดแชท Enter เปิดแชทและไปที่ช่องพิมพ์ข้อความ Shift+Enter เปิดเป็นหน้าต่างใหม่ |
| ข้อความ | ลูกศรขึ้น/ลง: ข้อความก่อนหน้า / ถัดไป Page Up/Page Down: ประมาณหนึ่งหน้าจอ Home: ข้อความเก่าสุดที่โหลดแล้ว (กดอีกครั้งเพื่อโหลดข้อความเก่าเพิ่ม) End: ข้อความล่าสุด ปุ่ม Applications หรือ Shift+F10: เมนูของข้อความ Enter หรือ Space: แสดงข้อความยาวทั้งหมด (อ่านได้เหมือนในโปรแกรม Word: ลูกศรขึ้น/ลงเลื่อนไปตามบรรทัดที่ LINE แสดง มีการขึ้นบรรทัดใหม่ (line feed) เฉพาะตรงที่ผู้เขียนขึ้นบรรทัดใหม่เอง Control+ลูกศรขึ้น/ลงเลื่อนทีละย่อหน้า กด Escape เพื่อกลับ) เล่นหรือหยุดข้อความเสียง เล่นเสียงของสติกเกอร์มีเสียงอีกครั้ง เปิดรูปภาพหรือวิดีโอในหน้าต่างดูรูปของ LINE (กด Tab ไปตามปุ่มและภาพย่อ กด Escape เพื่อปิดและกลับไปที่แชท) เปิดไฟล์ (PDF, Word ฯลฯ) ด้วยโปรแกรมของไฟล์นั้น เปิดลิงก์ (ที่อยู่เว็บแรกในข้อความ) ในเว็บเบราว์เซอร์ |
| เมนูของข้อความ | ลูกศรขึ้น/ลง Home/End เลื่อน Enter หรือ Space เลือก Escape ปิดเมนูและกลับไปที่ข้อความ |
| ช่องค้นหาในแชท | Enter: ค้นหา (เริ่มใหม่จากผลล่าสุด) ลูกศรขึ้น/ลง: ผลที่เก่ากว่า / ใหม่กว่า LINE MR อ่านลำดับผลการค้นหาและข้อความ |
| หน้าต่างผลการค้นหา | ลูกศรขึ้น/ลงเลื่อน Enter ไปที่ข้อความนั้นในแชท |
| การโทร | Enter หรือ Space บนปุ่มรับสาย / ปฏิเสธสาย; Alt+A รับสาย และ Alt+D ปฏิเสธสาย (ใน LINE; จากโปรแกรมอื่นใช้ NVDA+Shift+Control+A / D); Alt+D ใน LINE วางสายที่กำลังคุยอยู่ |

## ถ้า LINE MR ไม่ทำงาน

กด NVDA+Shift+Control+L ใน LINE แล้ว LINE MR จะบอกว่าเกิดปัญหาอะไร และเสนอวิธีแก้ถ้าแก้ได้

- **ยังไม่ได้ติดตั้งตัวเชื่อม / ตัวเชื่อมเป็นรุ่นเก่า / ต้องเปิด LINE ใหม่:** เลือก ใช่ แล้ว LINE จะปิดและเปิดใหม่พร้อมตัวเชื่อม การปิดหน้าต่าง LINE ไม่ได้ปิดโปรแกรม (LINE ยังทำงานอยู่ที่ถาดระบบ) LINE ที่เปิดไว้ก่อนติดตั้งตัวเชื่อมจึงยังทำงานโดยไม่มีตัวเชื่อมจนกว่าจะเปิดใหม่ LINE MR จะถามอีกครั้งเมื่อคุณกลับมาที่ LINE (ถ้าตอบ ไม่ จะถามอีกครั้งใน 10 นาที หรือกด NVDA+Shift+Control+L เพื่อให้ถามทันที)
- **LINE ติดตั้งไว้สำหรับผู้ใช้ทุกคน** (ใน Program Files): Windows จะขอสิทธิ์ผู้ดูแลระบบเพื่อเพิ่มตัวเชื่อมในโฟลเดอร์ของ LINE ให้กดอนุญาต
- **LINE เปิดขึ้นมาโดยไม่มีตัวเชื่อม LINE MR:** หลังติดตั้ง LINE MR จะตรวจว่า LINE โหลดตัวเชื่อมได้จริง ถ้าไม่ได้ แปลว่า Windows หรือโปรแกรมป้องกันไวรัสบล็อกไว้ ถ้าเปิด **Smart App Control** ของ Windows 11 อยู่ ระบบจะบล็อกตัวเชื่อม (ไฟล์ไม่มีลายเซ็นดิจิทัล) และ LINE MR จะใช้งานไม่ได้ ปิดได้ที่ Windows Security > App & browser control (เมื่อปิดแล้วจะเปิดกลับไม่ได้หากไม่ติดตั้ง Windows ใหม่) โปรแกรมป้องกันไวรัสก็อาจลบหรือบล็อก `line_a11y.dll` ได้เช่นกัน ให้อนุญาตไฟล์นี้ แล้วกด NVDA+Shift+Control+L ใน LINE อีกครั้ง
- **LINE MR ไม่รองรับ LINE รุ่นนี้:** LINE รุ่นเก่าเกินไปสำหรับตัวเชื่อม ให้อัปเดต LINE
- **ข้อความอ่านเป็น "รูปภาพหรือสติกเกอร์" หรืออ่านไม่ได้ แต่ปุ่มยังอ่านได้:** LINE ปิดตัวเองโดยไม่คาดคิดสองครั้งติดกัน ตัวเชื่อมจึงหยุดอ่านเนื้อหาข้อความเพื่อไม่ให้ LINE ปิดอีก ให้ออกจาก LINE ตามปกติ (จากเมนูของ LINE หรือไอคอนที่ถาดระบบ) แล้วเปิดใหม่

หากต้องการแจ้งปัญหา กด NVDA+Shift+Control+L **สองครั้ง** ใน LINE แล้ว LINE MR จะคัดลอกรายงานสั้น ๆ ไปยังคลิปบอร์ด รายงานมีรุ่นของ NVDA, Windows, LINE และ Qt, ตำแหน่งที่ติดตั้ง LINE, สถานะของตัวเชื่อม และ log ตอนเริ่มทำงาน ไม่มีเนื้อหาแชท และโฟลเดอร์ผู้ใช้ของคุณจะถูกแทนด้วย `%USERPROFILE%` นำไปวางในข้อความหรือ issue บน GitHub ได้เลย

## ตัวเชื่อมทำงานอย่างไร

ตัวเชื่อมคือไฟล์ `line_a11y.dll` ซึ่งเป็นปลั๊กอินธีมของ Qt วางไว้ที่ `%LOCALAPPDATA%\LINE\bin\current\platformthemes` และมีอีกชุดสำหรับโปรแกรมโทรของ LINE (`LineCall.exe` ซึ่งแสดงสายเรียกเข้าและหน้าต่างการโทร) ที่ `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<รุ่น>\platformthemes` และอีกชุดสำหรับหน้าต่างดูรูปภาพและวิดีโอของ LINE (`LineMediaPlayer.exe`) ที่ `%LOCALAPPDATA%\LINE\Data\plugin\LineMediaPlayer\<รุ่น>\platformthemes` LINE จะโหลดไฟล์นี้ตอนเริ่มทำงาน ตัวเชื่อมไม่เปลี่ยนหน้าตาของ LINE และอ่านข้อความจากสิ่งที่แต่ละส่วนวาด จึงไม่ขึ้นกับโครงสร้างหน่วยความจำภายในของ LINE ไม่มีการแก้ไขไฟล์ของ LINE เมื่อถอน LINE MR ใน Add-on Store ของ NVDA ไฟล์ DLL เหล่านี้และโฟลเดอร์ `%LOCALAPPDATA%\LineMR` (log และการตั้งค่า) จะถูกลบเมื่อ NVDA เริ่มทำงานใหม่ ถ้า LINE เปิดอยู่ LINE จะยังใช้ตัวเชื่อมต่อไปจนกว่าจะออกจาก LINE หาก LINE ติดตั้งสำหรับผู้ใช้ทุกคน (Program Files) ให้ลบไฟล์ DLL ในโฟลเดอร์ของ LINE เอง

บันทึกการทำงาน: `%LOCALAPPDATA%\LineMR\logs\bridge.log`

LINE MR เป็นโครงการอิสระ ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจาก LY Corporation / LINE
