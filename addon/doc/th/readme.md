# LINE MR (ไลน์ไม่รู้) สำหรับ NVDA

LINE MR ทำให้ผู้ใช้ NVDA ใช้ [LINE บน Windows](https://line.me) ได้

LINE วาดปุ่มและข้อความเอง โปรแกรมอ่านหน้าจอจึงแทบไม่เห็นอะไรเลย ปุ่มไม่มีชื่อและอ่านข้อความไม่ได้ LINE MR เพิ่มตัวเชื่อมการเข้าถึงขนาดเล็กเข้าไปใน LINE เพื่อให้ปุ่มและข้อความมีชื่อ บทบาท และใช้งานได้ พร้อมโมดูลแอปของ NVDA ที่จัดการสิ่งที่ NVDA อ่านให้เรียบร้อย

## การติดตั้ง

**แนะนำ: ติดตั้ง [LINE จาก Microsoft Store](https://apps.microsoft.com/detail/XPFCC4CD725961)** (LINE Desktop ของ LY Corporation หรือเปิดแอป Microsoft Store แล้วค้นหา "LINE") LINE MR พัฒนาและทดสอบกับ LINE รุ่นจาก Microsoft Store จึงทำงานเข้ากันได้มากที่สุด รุ่นนี้ติดตั้ง LINE ไว้ที่ `%LOCALAPPDATA%\LINE` และอัปเดตให้อัตโนมัติ หากใช้ LINE จากแหล่งอื่น อาจติดตั้งไว้ที่อื่นหรือเป็นรุ่นที่ต่างออกไป ทำให้ติดตั้งหรือใช้ตัวเชื่อมไม่ได้

1. ติดตั้งส่วนเสริมนี้แล้วเปิด NVDA ใหม่
2. เปิด LINE (หรือสลับไปที่ LINE) LINE MR จะถามว่าต้องการติดตั้งตัวเชื่อมใน LINE หรือไม่ ให้เลือก **ใช่** LINE จะปิดแล้วเปิดใหม่พร้อมตัวเชื่อม

หลัง LINE อัปเดต อาจต้องติดตั้งตัวเชื่อมใหม่ LINE MR จะตรวจพบและถามอีกครั้ง

## การอัปเดต LINE MR

เมื่อเปิด NVDA LINE MR จะตรวจหารุ่นใหม่บน GitHub ถ้ามี จะแสดงหน้าต่างให้เลือก **อัปเดตตอนนี้** **ไว้ทีหลัง** หรือ **ข้ามรุ่นนี้** เมื่อเลือกอัปเดตตอนนี้ LINE MR จะดาวน์โหลดรุ่นใหม่แล้วส่งให้ NVDA ติดตั้ง NVDA จะถามยืนยันการติดตั้ง แล้วถามให้เริ่ม NVDA ใหม่ หากต้องการปิดการตรวจหรือตรวจทันที ไปที่ เมนู NVDA, ค่าติดตั้ง, การตั้งค่า หมวด "LINE MR" คำสั่ง "ตรวจหา LINE MR รุ่นใหม่" ไม่มีปุ่มลัดตั้งต้น กำหนดปุ่มได้ที่ คำสั่งป้อนเข้า

## สิ่งที่ใช้ได้ตอนนี้

- หน้าต่างเข้าสู่ระบบ: ช่องอีเมลและรหัสผ่าน ปุ่มเข้าสู่ระบบ กล่องกาเครื่องหมาย "เข้าสู่ระบบอัตโนมัติ" คำแนะนำคิวอาร์โค้ด และปุ่มบนแถบชื่อเรื่องมีชื่อครบ
- ปุ่มที่มีแต่ไอคอนจะมีชื่อตามไอคอน เป็นภาษาเดียวกับที่ LINE ใช้ (ไทยหรืออังกฤษ)
- แป้นพิมพ์: กด Tab และ Shift+Tab ไปถึงทุกปุ่ม กล่องกาเครื่องหมาย และลิงก์ตามลำดับการอ่าน (เนื้อหาของหน้าต่างก่อน ปุ่มบนแถบชื่อเรื่องอยู่ท้ายสุด) กด Space หรือ Enter เพื่อกดสิ่งที่โฟกัสอยู่ ปกติ LINE ให้ Tab ไปได้แค่ช่องข้อความ
- NVDA อ่านตามโฟกัสเมื่อเลื่อนไปมา (ปกติ LINE ปิดการแจ้งเหล่านี้ไว้ ตัวเชื่อมเปิดกลับมาให้)
- กล่องกาเครื่องหมายบอกสถานะและเปลี่ยนสถานะได้ ("กาเครื่องหมาย" / "ไม่ได้กาเครื่องหมาย")
- ข้อความที่คลิกได้ เช่น "เข้าสู่ระบบด้วยสมาร์ทโฟน >" เป็นลิงก์ เมื่อกดแล้วหน้าจอเปลี่ยน โฟกัสจะไปที่ช่องแรกของหน้าจอใหม่
- เมื่อเข้าหน้าต่างเข้าสู่ระบบ NVDA จะอ่านคำแนะนำ (เช่น วิธีสแกนคิวอาร์โค้ด) กด NVDA+B เพื่ออ่านอีกครั้ง
- ซ่อนหน้าต่างเงาของ LINE และกลุ่มจัดวางที่ไม่มีชื่อจากการนำทางวัตถุ
- หน้าต่างหลัก: แท็บด้านข้าง ปุ่มบนหัวแชท และปุ่มบนแถบพิมพ์ข้อความมีชื่อ รายการแชทอ่านชื่อ จำนวนสมาชิก ข้อความล่าสุด เวลา และจำนวนที่ยังไม่อ่าน รายชื่อเพื่อนอ่านชื่อ จำนวนสมาชิก และหมวดกลุ่ม
- รายการแชท: ลูกศรขึ้น/ลง Page Up/Page Down และ Home/End เลื่อนดูแชทได้เร็วโดยไม่เปิดแชท (การเปิดแชททำให้ LINE ค้างได้ถึงสองวินาที) กด Enter เพื่อเปิดแชทและไปที่ช่องพิมพ์ข้อความ แชททางขวาจะเปลี่ยนเมื่อกด Enter เท่านั้น
- ข้อความ: อ่านผู้ส่ง (หรือ "คุณ") ข้อความ เวลา และสถานะอ่านแล้ว ข้อความที่ไม่ใช่ตัวอักษรจะบอกประเภท ได้แก่ รูปภาพ อัลบั้มรูปภาพ วิดีโอ สติกเกอร์ อีโมจิ LINE ข้อความเสียง (พร้อมความยาว) ไฟล์ (พร้อมชื่อและขนาด) ตำแหน่งที่ตั้ง (พร้อมที่อยู่) และการโทร (พร้อมระยะเวลาหรือสถานะ) เมื่อเข้ารายการข้อความ (Tab, Shift+Tab หรือ Alt+M) จะเริ่มที่ข้อความล่าสุด ลูกศรขึ้น/ลง เลื่อนทีละข้อความ Page Up/Page Down เลื่อนประมาณหนึ่งหน้าจอ Home ไปที่ข้อความเก่าสุดที่โหลดแล้ว (LINE โหลดข้อความเก่าเพิ่ม กด Home อีกครั้งเพื่อย้อนต่อ) End ไปที่ข้อความล่าสุด กด Home หรือ End ซ้ำเพื่ออ่านข้อความนั้นอีกครั้ง ข้อความใหม่จากผู้อื่นจะถูกอ่านเมื่อ LINE อยู่หน้าสุด
- ลำดับ Tab ในแผงรายการแชท: เรียงลำดับ แสดงหรือซ่อนรายการแชท สร้างแชท โฆษณา ช่องค้นหา แล้วจึงเป็นรายการแชท (กด Tab ต่อไปที่แชทที่เปิดอยู่)
- ลำดับ Tab ในแชทที่เปิดอยู่: ปุ่มบนหัวแชท โน้ตของแชท (ถ้ามี) "เลื่อนไปข้อความล่าสุด" รายการข้อความ ช่องพิมพ์ข้อความ แล้วตามด้วยปุ่มบนแถบพิมพ์ข้อความจากช่องพิมพ์ออกไป (สติกเกอร์และอีโมจิ ตัวเลือกการจับภาพหน้าจอ จับภาพหน้าจอ Keep แนบไฟล์)
- เมนูบริบท: ปุ่ม Applications (หรือ Shift+F10) บนข้อความเปิดเมนูของ LINE โฟกัสไปที่รายการแรก ลูกศรขึ้น/ลง Home/End เลื่อนในเมนู Enter หรือ Space เลือก Escape ปิดเมนูและกลับไปที่ข้อความ
- สายเรียกเข้า: LINE MR จะพูดว่า "สายเรียกเข้า" พร้อมชื่อผู้โทร แม้กำลังใช้โปรแกรมอื่นอยู่ กด NVDA+Shift+Control+A เพื่อรับสาย หรือ NVDA+Shift+Control+D เพื่อปฏิเสธสาย ใช้ได้จากทุกโปรแกรม โฟกัสจะไปที่ปุ่มรับสายในหน้าต่างสายเรียกเข้า (กด Tab ไปที่ปุ่มปฏิเสธสาย กด Enter หรือ Space เพื่อกด) ระหว่างการโทร ปุ่มในหน้าต่างการโทรมีชื่อครบ (วางสาย ปิดไมโครโฟน เริ่มวิดีโอคอล ปิดเสียง) และอ่านข้อความในหน้าต่างได้ (ชื่อผู้โทร ระยะเวลาการโทร)
- หน้าที่เปิดเป็นหน้าต่างใหม่อ่านได้แล้ว: กดชื่อกลุ่มหรือจำนวนสมาชิก (เช่น "(5)") จะเปิดรายชื่อสมาชิก กดสมาชิกจะเปิดโปรไฟล์ เมนูของแชท รูป & วิดีโอ ลิงก์ และไฟล์ เปิดหน้าต่างที่ใช้ชื่อแชท โฟกัสเริ่มที่ตัวควบคุมแรกของหน้านั้นและอ่านข้อความในหน้า หน้าที่เปิดในหน้าต่างหลักก็ได้รับโฟกัสเช่นกัน
- หน้าต่างอื่น ๆ: การตั้งค่า (เพิ่มเติม > ตั้งค่า หมวดและหมวดย่อยเป็นปุ่มตัวเลือก กล่องรายการมีชื่อตามหัวข้อ) ตั้งค่าโปรไฟล์ อัลบั้มและโน้ต ค้นหาเพื่อน และสร้างกลุ่ม (เพื่อนแต่ละคนเป็นกล่องกาเครื่องหมาย กด Space เพื่อเลือก) โหวตเปิดเป็นหน้าเว็บ อ่านด้วยโหมดเรียกดู
- ข้อความแบบรูปภาพ (การ์ดจากบัญชีทางการ เช่น ธนาคาร) เป็นรูปที่มีตัวอักษรอยู่ในรูป LINE จึงไม่มีข้อความให้อ่าน จะอ่านว่า "รูปภาพหรือสติกเกอร์" กด NVDA+R บนข้อความนั้นเพื่ออ่านตัวอักษรด้วย OCR ของ Windows ถ้า LINE ดาวน์โหลดการ์ดไม่ได้ จะแสดง "ไม่สามารถโหลดได้" และปุ่ม "ลองอีกครั้ง" ซึ่งเป็นสิ่งที่ได้ยิน

## คำสั่ง

| คำสั่ง | การทำงาน |
|---|---|
| Alt+1 / Alt+2 / Alt+3 | แท็บเพื่อน / แชท / เพิ่มเพื่อน |
| Alt+C | ไปที่รายการแชท (สลับไปที่แท็บแชทก่อนถ้าจำเป็น) |
| Alt+L | ไปที่รายการแชทหรือรายชื่อเพื่อน (รายการที่แสดงอยู่) |
| Alt+M | ไปที่ข้อความของแชทที่เปิดอยู่ |
| Alt+I | ไปที่ช่องพิมพ์ข้อความ |
| NVDA+Alt+1 … NVDA+Alt+9 | อ่านข้อความล่าสุด (1 = ใหม่สุด) |
| NVDA+Shift+Control+A | รับสายเรียกเข้าของ LINE (ใช้ได้จากทุกโปรแกรม) |
| NVDA+Shift+Control+D | ปฏิเสธสายเรียกเข้าของ LINE (ใช้ได้จากทุกโปรแกรม) |
| NVDA+Shift+Control+L | บอกว่าตัวเชื่อม LINE MR ทำงานอยู่หรือไม่ (และเสนอให้ติดตั้ง) |

เปลี่ยนคำสั่งได้ที่ เมนู NVDA, ค่าติดตั้ง, คำสั่งป้อนเข้า หมวด "LINE MR"

### ปุ่มที่ใช้ใน LINE

| ที่ไหน | ปุ่ม |
|---|---|
| ทุกที่ | Tab / Shift+Tab ไปยังตัวควบคุมถัดไป / ก่อนหน้า Space หรือ Enter กดปุ่ม กล่องกาเครื่องหมาย และลิงก์ |
| รายการแชท | ลูกศรขึ้น/ลง Page Up/Page Down Home/End เลื่อนดูแชทโดยไม่เปิดแชท Enter เปิดแชทและไปที่ช่องพิมพ์ข้อความ |
| ข้อความ | ลูกศรขึ้น/ลง: ข้อความก่อนหน้า / ถัดไป Page Up/Page Down: ประมาณหนึ่งหน้าจอ Home: ข้อความเก่าสุดที่โหลดแล้ว (กดอีกครั้งเพื่อโหลดข้อความเก่าเพิ่ม) End: ข้อความล่าสุด ปุ่ม Applications หรือ Shift+F10: เมนูของข้อความ |
| เมนูของข้อความ | ลูกศรขึ้น/ลง Home/End เลื่อน Enter หรือ Space เลือก Escape ปิดเมนูและกลับไปที่ข้อความ |
| สายเรียกเข้า | Enter หรือ Space บนปุ่มรับสาย / ปฏิเสธสาย หรือ NVDA+Shift+Control+A / D จากทุกโปรแกรม |

## ตัวเชื่อมทำงานอย่างไร

ตัวเชื่อมคือไฟล์ `line_a11y.dll` ซึ่งเป็นปลั๊กอินธีมของ Qt วางไว้ที่ `%LOCALAPPDATA%\LINE\bin\current\platformthemes` และมีอีกชุดสำหรับโปรแกรมโทรของ LINE (`LineCall.exe` ซึ่งแสดงสายเรียกเข้าและหน้าต่างการโทร) ที่ `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<รุ่น>\platformthemes` LINE จะโหลดไฟล์นี้ตอนเริ่มทำงาน ตัวเชื่อมไม่เปลี่ยนหน้าตาของ LINE และอ่านข้อความจากสิ่งที่แต่ละส่วนวาด จึงไม่ขึ้นกับโครงสร้างหน่วยความจำภายในของ LINE ไม่มีการแก้ไขไฟล์ของ LINE หากต้องการเอาออก ให้ลบไฟล์ DLL เหล่านั้น

บันทึกการทำงาน: `%LOCALAPPDATA%\LineMR\logs\bridge.log`

LINE MR เป็นโครงการอิสระ ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจาก LY Corporation / LINE
