# LINE MR の新機能

## バージョン 0.6.0

### キー
- 新機能: メッセージ一覧で Alt+Shift+R を押すと、選択したメッセージのリアクションが開きます (メニューの「リアクション」)。すでにリアクションしている場合は、取り消すために開きます。
- 文字や数字のコマンド (Alt+C、Alt+M、Alt+1 など) が、タイ語などラテン文字以外のキーボード配列でも使えるようになりました。英語キーボードで同じ位置のキーとして扱われるので、先に英語へ切り替える必要はありません。
- メッセージ一覧の Alt+T は選択したメッセージの翻訳になりました (LINE のメッセージメニューの「翻訳」)。ボイスメッセージの文字起こしは Alt+Shift+T に移りました。
- Alt+C、Alt+L、Alt+F、Alt+1 / Alt+2 / Alt+3 は別ウィンドウで開いたトークからも使えるようになりました: LINE のメイン ウィンドウが前面に出て、そこにフォーカスが移ります。トーク ルームを非表示にしたメイン ウィンドウでは、Alt+M と Alt+I でトークのウィンドウに移ります。

### ボイスメッセージを文字に
- 動画も文字に起こせるようになりました: トークの動画 (メニュー: 「動画の音声を文字に起こす」)、「写真・動画」、ノート、LINE のビューアーで Alt+Shift+T を押します。LINE に動画を LINE MR のフォルダーへ保存させ、終わったらファイルを削除します。5 分を超えるボイスメッセージや動画は、変換がこのコンピューター上で行われ時間がかかることがあるため、先に確認します。
- 文字起こしは常に選択したメッセージのファイルを使います: LINE が LINE MR のフォルダー (%LOCALAPPDATA%\LineMR\media) に保存し (「名前を付けて保存」ウィンドウが一瞬表示されます)、文字ができたらファイルを削除します。再生はしません。保存後、LINE はそのメッセージのメニューに「名前を付けて保存」ではなく「フォルダーを開く」を表示します。ファイルを削除したあと LINE MR が裏で「フォルダーを開く」を押すので (何も開きません)、メニューは「名前を付けて保存」に戻ります。以前は LINE のキャッシュから同じ長さの別のメッセージを取り、その文字を表示することがありました。LINE が保存できないボイスメッセージ (期限切れ) は、これまでどおり再生して録音します。
- ボイスメッセージや動画のテキストが変換しながら表示され (音声 30 秒ごと)、その間に読んだり編集したりできるようになりました。新しい行はカーソルを動かさずに末尾に追加され、編集した内容は保持されます。
- 30 秒を超える録音は変換前に話の切れ目で分けられるようになり、30 秒ごとに語が重複したり抜けたりしなくなりました。「コピー」はテキストがそろってから表示されます。音声モデルの一覧は GitHub の LINE MR リポジトリから取得され、新しいモデルはアドオンを更新しなくても設定とダイアログに表示されます。
- 新機能: ボイスメッセージの上で Alt+Shift+T (またはメニューの「ボイスメッセージを文字に起こす」) を押すと、このコンピューター上で文字に起こします。テキストはウィンドウに表示され、読む・編集する・コピーすることができます。初期状態ではオフです。NVDA の設定の LINE MR カテゴリでオンにすると、そこで選んだ音声モデルを一度だけダウンロードします。モデルは 6 つ: Typhoon Whisper Turbo (874 MB、初期値。タイ語に最適で英語と日本語にも対応、Typhoon の中で最もメモリーが少ない)、Typhoon Whisper Medium と Large v3 (タイ語のみ。Large v3 は最も正確ですがとても遅い)、OpenAI の Whisper Small・Medium・Large v3 Turbo (多言語)。または「モデルファイルを選ぶ」で自分の whisper.cpp モデルを使えます (LINE MR が使う前に確認します)。毎回の文字起こしの前のダイアログでモデルと言語を尋ねます。ガイドの「ボイスメッセージを文字に」を参照してください。

### メッセージの保存
- 新機能: メッセージ一覧で Ctrl+S を押すと、選択したメッセージを保存します。写真・動画・ファイル・ボイスメッセージ: LINE の「名前を付けて保存」(LINE が保存先を尋ねます)。テキストメッセージ (長いものも全文)・位置情報・連絡先: テキストファイル (.txt)。LINE MR が保存先を尋ねます。スタンプ・通話・日付・お知らせ: 保存できないと LINE MR が伝えます。ほかの場所では Ctrl+S は通常どおり動作し、NVDA の入力ジェスチャーで変更できます。

### 写真・動画
- 複数の写真や動画をまとめて保存・共有できるようになりました (#9): トークの「写真・動画」ウィンドウ(トーク メニュー)で Space を押すとカーソル位置の項目を選択し、NVDA が選択されているかどうかを読み上げます。Tab で一覧の下にある LINE のバー(選択した数、共有、Keep メモに送信、ダウンロード、キャンセル)に移動できます。ダウンロードでは保存先フォルダーを選びます。キャンセルですべての選択を解除して一覧に戻ります。Enter は従来どおり項目を開きます。トークで送られたアルバムの写真もここにあります。LINE 自体も複数の写真をまとめて保存できるのはこのウィンドウだけです。

### チャットリスト
- トーク ルームを非表示にしている場合(トーク ルームの表示/非表示ボタン)、Enter または Space ですぐにトークを別ウィンドウで開き、メッセージ入力欄に移動します。以前は 1 回目でトークが選択されるだけで、もう一度押す必要がありました。トーク リストでは Space も Enter と同じになりました。トークをまだ開いていないときも、表示/非表示ボタンが正しい状態を読み上げます。
- 新機能: トーク リストで Shift+Enter を押すと、トークを別ウィンドウで開き(トークのメニューの「新しいウィンドウで開く」と同じ)、メッセージ入力欄に移動します。
- 未読数は「未読メッセージ 3 件」と読みます (以前は「未読 3」)。位置はこれまでどおりチャットの行の最後です。
- グループとオープンチャットは、トーク名の後にその種類を読み上げます: 「DHCB, グループ, メンバー 37 人, ...」「English talk, オープンチャット, ...」(#5)。公式アカウントは LINE が区別できる情報を出さないため、友だちと区別できません。

### 設定
- NVDA の設定のカテゴリ「LINE MR」に、ブリッジが動作しているかの表示と、ブリッジを切断する(LINE MR なしで LINE をそのまま使う)または再び接続するボタンを追加しました。どちらでも LINE は再起動します。
- NVDA のアドオン ストアで LINE MR を削除すると、LINE、通話プログラム、写真ビューアーからブリッジが、また LINE MR のフォルダー `%LOCALAPPDATA%\LineMR` も削除されるようになりました。実行中の LINE は終了するまでブリッジを使い続けます。

### メッセージ
- 長いメッセージや一部の受信メッセージのメニューに「リアクション」が出ませんでした。お知らせと判定されていたためで、修正しました (#3)。
- Enter でトークを開くと、最新のメッセージへ飛ばずに LINE の位置 (たとえば最初の未読メッセージ) が保たれます。メッセージ入力欄から Shift+Tab でメッセージに戻ると、画面に表示中の位置のままです (最後に読んだメッセージが見えていればそこ、なければ画面上の最初のメッセージ)。wengweng0312 さんの貢献 (#20)。
- メッセージ一覧で Alt+R を押すと選択したメッセージに返信してメッセージ入力欄へ移動し、Delete で削除、Shift+Delete で送信を取り消します(LINE のメッセージ メニューの項目です。LINE の確認には自分で答えます)。それ以外の場所ではキーは通常どおりで、NVDA の入力ジェスチャーで変更できます(wengweng0312 さんの貢献)。
- メッセージのメニューで「返信」を選ぶとメッセージ入力欄へ移動します(wengweng0312 さんの貢献)。
- 返信中、メッセージ入力欄の上のバーに移動できるようになりました: メッセージ入力欄で Shift+Tab を押すと「リプライをキャンセル」と「元のメッセージへ移動」に移ります。キャンセルするとメッセージ入力欄に戻ります。
- NVDA の設定のカテゴリ「LINE MR」に新しいオプション「1 対 1 のトークで送信者の名前を表示」: 相手のメッセージの前に相手の名前を読み上げます(既定はオフ)。LINE が時刻を表示しない自分の長いメッセージも自分のものとして読みます(wengweng0312 さんの貢献)。
- トーク一覧で Enter を押すと、開いたトークのメッセージ入力欄にとどまります: LINE はトークの読み込み後にフォーカスをメッセージ一覧へ移すことがありました。開いているトークでは、Tab は常にメッセージ一覧、メッセージ入力欄、その下のボタンの順に移動します。
- グループトークのメンション(@): @ を入力すると、上下矢印で LINE が候補に出すメンバーを読み上げ、続けて入力すると絞り込み、Enter で選びます。これまでは矢印キーが効きませんでした(wengweng0312 さんの貢献)。メッセージ入力欄では選んだメンバーを「@名前」と読み上げます(これまでは何も読み上げませんでした)。
- メッセージは LINE 自身のテキストで読み上げます(LINE 26.6 以降): すべてのメッセージの送信者と時刻、返信の全文、ファイル名の全体、画面外のメッセージも含みます。LINE が示さないもの(自分のメッセージの前の「あなた」、スタンプと通話、リアクション)は LINE MR が補います(wengweng0312 さんの貢献)。ブリッジが読む長さ(通話、LINE のテキストがないボイスメッセージと動画)は「00:07」「10:54」ではなく「7秒」「10分54秒」と読み上げます。
- LINE 自身のテキストにない情報も読み上げます: ファイルのサイズと保存期限、リンクのプレビューのタイトル、住所の前の「位置情報」、「連絡先」と名前、「写真」の代わりに「写真アルバム」。返信は返信内容から読み上げます:「X、Y への返信: <返信>、元のメッセージ: <引用>」。Keep メモではすべてのメッセージを「あなた」と読み、日本語・中国語の LINE の時刻と既読を認識するので、そこでも自分のメッセージが「あなた」と読まれます。
- NVDA の設定のカテゴリ「LINE MR」に新しいオプション「送信者が変わったときだけ送信者の名前を読み上げる」(既定はオフ): 同じ人の続くメッセージは本文から始まります。

## バージョン 0.5.5

### 更新
- NVDA のアドオンストアからインストールした場合、更新はアドオンストアに任せます。LINE MR は GitHub を確認せず、設定にもそう表示されます。

### フォーカスの強調表示
- ロービジョンの方のために、LINE でフォーカスのあるコントロール(チャット、メッセージ、メニュー項目も)を黒い縁取りの黄色い枠で示します。色と太さの変更やオフは、NVDA の設定のカテゴリ LINE MR でできます。

### 修正
- NVDA 2025.4 以前(32 ビット版 NVDA)では、LINE MR が動作しているのに LINE の再起動を何度も求めていました。LINE MR が動作していることを正しく検出するようになりました。
- メッセージ入力欄などのテキスト欄で、上下矢印キーが画面に表示された行を読むようになりました。折り返された長い段落は、行ごとに段落全体を繰り返さず 1 行ずつ読み、空行は前の行ではなく「空行」と読みます。
- メッセージ入力欄で文章を 1 行ずつ読んでいるとき、上下矢印キーでフォーカスが(上にある LINE のスタンプと絵文字のおすすめへ)移動しなくなりました。
- 読み込まれた最も古いメッセージで上矢印キーを押すと、LINE がさらに古いメッセージを読み込み、そのまま上に進めます(wengweng0312 さんの貢献)。
- 設定のチェックボックスをキーボードで変更した内容(例:通知 > メッセージ内容を表示)が保存されるようになりました(wengweng0312 さんの貢献)。
- LINE が複数の部品で描くボイスメッセージを認識し、Enter や Space で再生できます(wengweng0312 さんの貢献)。
- 繁体字中国語の LINE:既読(已讀)と時刻(下午 2:49)をメッセージの最後に読み、「已讀」と書かれた受信メッセージを既読表示と取り違えません(Keyang556 さんの貢献)。

## バージョン 0.5.4

### 長いメッセージ
- 長いメッセージの全文(「もっと見る」)では、Word と同じように、書き手が改行した所でだけ NVDA が「改行」と読みます。上下矢印は今までどおり LINE が表示する行ごとに移動します。

### メッセージ
- リンクを含む一部のメッセージ(YouTube のリンクなど)が「通話」と読まれていました。現在は LINE の通話メッセージだけが「通話」と読まれます。「写真またはスタンプ」と読まれていたビデオ通話も「通話」と読まれます。

### トークリスト
- 開いているトークは名前の前に「選択中」、ピン留めしたトークは名前の後に「ピン留め」と読みます。

### トーク作成(トーク、グループトーク、オープンチャット)
- 友だち選択は検索欄にフォーカスがある状態で開きます。上下矢印、Page Up/Page Down、Home/End で全員の間を移動し、Space でチェックします。Tab でリストを出て、選んだ友だち(「<名前> を取り除く」)と「次へ」に移ります。Shift+Tab で最後に読んだ友だちに戻ります。
- グループのプロフィール設定ページでは、プロフィール画像を変更、背景画像を変更、グループ名を編集のボタンに名前が付きます。「メンバーが自動で参加」はチェックボックスで、Space で切り替えます。
- オープンチャット作成では、キーワード欄とカテゴリーに名前が付き、欄の中の × は「テキストをクリア」と読みます。「次へ」の後は「このオープンチャットでのニックネーム」にフォーカスが移り、ページの目的も読み上げます。
- テキストでプロフィールを作成(プロフィール画像を変更 > テキストでプロフィールを作成)では、色は番号と色名の付いたチェックボックス(「色 4: 明るいピンク」)で、Space で選びます。文字の色 / 背景色で色を変える対象を選びます。フォント一覧は「フォント」です。

### ノート
- ノート(グループ、オープンチャット)の投稿を、投稿者、写真・動画、リアクションとコメントの数、時刻と一緒に読み上げます。矢印キーで投稿ごとに移動し、Enter で投稿の動画を LINE の動画プレーヤーで再生します(フォーカスは再生/一時停止)。Escape で投稿に戻ります。
- 投稿でアプリケーション キーを押すと、開く、名前を付けて保存...、テキストをコピー、その他のオプション(LINE のメニュー)のメニューが開きます。LINE のビューアーでは Ctrl+S で写真や動画を保存します。

### 設定
- NVDA の設定の LINE MR カテゴリーに、この「新機能」ボタンを追加しました。

## バージョン 0.5.3
- メッセージのメニュー(アプリケーション キー)に「リアクション」を追加しました。メッセージに付いているリアクションも読み上げます。
- スタンプのパッケージを名前で読みます。最初の Enter でスタンプや絵文字を選んでプレビューし、2 回目の Enter で送信します。
- グループでは、メッセージのメニューに「<名前> のプロフィールを表示」があります。トーク内検索の結果を読み上げます。
- 写真・動画、リンク、ファイルの一覧を矢印キーで移動し、Enter で開けます。動画プレーヤーでは Space で再生・一時停止、矢印キーで早送り・巻き戻しします。
- 通話中に LINE がほかの音を下げても、NVDA の音量は下がりません。ビデオ通話のウィンドウでは、カメラとマイクがオンかどうかを読み上げます。

## バージョン 0.5.2

- 音声メッセージ、ファイル、写真でアプリケーション キーを押すと、そのメッセージのメニューを開きます。
- Tab でメッセージに戻ると、最後に読んだメッセージに戻ります。長いメッセージを行ごとに速く読めます。
