# LINE MR の新機能

## バージョン 0.5.4

### 長いメッセージ
- 長いメッセージの全文(「もっと見る」)では、Word と同じように、書き手が改行した所でだけ NVDA が「改行」と読みます。上下矢印は今までどおり LINE が表示する行ごとに移動します。

### メッセージ
- リンクを含む一部のメッセージ(YouTube のリンクなど)が「通話」と読まれていました。現在は LINE の通話メッセージだけが「通話」と読まれます。「写真またはスタンプ」と読まれていたビデオ通話も「通話」と読まれます。

### トークリスト
- 開いているトークは名前の前に「選択中」、ピン留めしたトークは名前の後に「ピン留め」と読みます。

### トーク作成(トーク、グループトーク、オープンチャット)
- 友だち選択は検索欄にフォーカスがある状態で開きます。上下矢印、Page Up/Page Down、Home/End で全員の間を移動し、Space でチェックします。Tab でリストを出て、選んだ友だち(「<名前> を取り除く」)と「次へ」に移ります。Shift+Tab で最後に読んだ友だちに戻ります。
- グループのプロフィール設定ページでは、プロフィール画像を変更、背景画像を変更、グループ名を編集のボタンに名前が付きます。「メンバーが自動で参加」はチェックボックスで、Space で切り替えます。
- オープンチャット作成では、キーワード欄とカテゴリーに名前が付き、欄の中の × は「テキストをクリア」と読みます。「次へ」の後は「このオープンチャットでのニックネーム」にフォーカスが移り、ページの目的も読み上げます。
- テキストでプロフィールを作成(プロフィール画像を変更 > テキストでプロフィールを作成)では、色は番号と色名の付いたチェックボックス(「色 4: 明るいピンク」)で、Space で選びます。文字の色 / 背景色で色を変える対象を選びます。フォント一覧は「フォント」です。

### ノート
- ノート(グループ、オープンチャット)の投稿を、投稿者、写真・動画、リアクションとコメントの数、時刻と一緒に読み上げます。矢印キーで投稿ごとに移動し、Enter で投稿の動画を LINE の動画プレーヤーで再生します(フォーカスは再生/一時停止)。Escape で投稿に戻ります。
- 投稿でアプリケーション キーを押すと、開く、名前を付けて保存...、テキストをコピー、その他のオプション(LINE のメニュー)のメニューが開きます。LINE のビューアーでは Ctrl+S で写真や動画を保存します。

### 設定
- NVDA の設定の LINE MR カテゴリーに、この「新機能」ボタンを追加しました。

## バージョン 0.5.3
- メッセージのメニュー(アプリケーション キー)に「リアクション」を追加しました。メッセージに付いているリアクションも読み上げます。
- スタンプのパッケージを名前で読みます。最初の Enter でスタンプや絵文字を選んでプレビューし、2 回目の Enter で送信します。
- グループでは、メッセージのメニューに「<名前> のプロフィールを表示」があります。トーク内検索の結果を読み上げます。
- 写真・動画、リンク、ファイルの一覧を矢印キーで移動し、Enter で開けます。動画プレーヤーでは Space で再生・一時停止、矢印キーで早送り・巻き戻しします。
- 通話中に LINE がほかの音を下げても、NVDA の音量は下がりません。ビデオ通話のウィンドウでは、カメラとマイクがオンかどうかを読み上げます。

## バージョン 0.5.2
- リンクのあるメッセージで Enter を押すと、ブラウザーでリンクを開きます。
- 音声メッセージ、ファイル、写真でアプリケーション キーを押すと、そのメッセージのメニューを開きます。
- Tab でメッセージに戻ると、最後に読んだメッセージに戻ります。長いメッセージを行ごとに速く読めます。

## バージョン 0.5.1
- Enter または Space で、メッセージの中身(音声、動画、写真、ファイル)を開きます。
- LINE の写真・動画ビューアーでも使えます。トークのフォルダー タブで一覧を絞り込めます。
- より多くのパソコンにインストールできます。NVDA+Shift+Control+L を 2 回押すと、開発者向けのレポートをコピーします。

## バージョン 0.5.0
- 長いメッセージをメモ帳のように行ごとに読めます。
- Alt+F で検索欄に移動します。Alt+A / Alt+D で着信に応答または拒否します。
- 日本語、簡体字中国語、繁体字中国語に対応しました。

## バージョン 0.4.5
- 長いメッセージを全部読みます。トークリスト パネルの Tab 順序を変更しました。

## バージョン 0.4.4
- 動画、ファイル、位置情報、スタンプを LINE のアイコンで見分けます。

## バージョン 0.4.3
- 着信を知らせ、応答できます。音声メッセージを長さと一緒に読みます。Alt+C でトークリストに移動します。
