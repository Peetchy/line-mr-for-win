# LINE MR (Line Mai Roo) for NVDA

LINE MR は、[LINE for Windows](https://line.me) を NVDA で使えるようにするアドオンです。

LINE はボタンや文字を独自に描画しているため、そのままではスクリーンリーダーにほとんど情報を提供しません。ボタンには名前がなく、文字も読み上げられません。LINE MR は、LINE のコントロールに名前・役割・操作を与える小さなアクセシビリティ ブリッジを LINE に追加し、さらに NVDA が読み上げる内容を整理する NVDA アプリモジュールを提供します。

## インストール

**推奨: [Microsoft Store 版の LINE](https://apps.microsoft.com/detail/XPFCC4CD725961) をインストールしてください**(LY Corporation の「LINE Desktop」。Microsoft Store アプリで「LINE」と検索しても見つかります)。LINE MR は Microsoft Store 版で開発・テストしているため、最も高い互換性が得られます。Microsoft Store 版は LINE を `%LOCALAPPDATA%\LINE` にインストールし、自動的に最新の状態に保ちます。ほかの入手元の LINE は別の場所にインストールされたり、別のビルドであったりするため、ブリッジをインストールできない、または動作しない場合があります。

1. アドオンをインストールし、NVDA を再起動します。
2. LINE を起動します(または LINE に切り替えます)。LINE MR がブリッジを LINE にインストールするか尋ねるので、**はい** を選びます。LINE がいったん終了し、ブリッジを読み込んだ状態で再び起動します。

LINE の更新後はブリッジを再度インストールする必要がある場合があります。LINE MR がそれを検出し、もう一度尋ねます。

## LINE MR の更新

NVDA の起動時に、LINE MR は GitHub で新しいリリースがあるか確認します。新しいリリースがある場合は、**今すぐ更新**、**後で**、**このバージョンをスキップ** を選べるダイアログが表示されます。「今すぐ更新」を選ぶと新しいバージョンをダウンロードして NVDA に渡します。NVDA がインストールの確認と NVDA の再起動を求めます。確認をオフにする、またはすぐに確認するには: NVDA メニュー、設定、設定、カテゴリ「LINE MR」。コマンド「LINE MR の新しいバージョンを確認」(既定ではキー未割り当て)には、入力ジェスチャーでキーを割り当てられます。

同じカテゴリーの **新機能** ボタンで、バージョンごとの変更点を Web ページのように読めるウィンドウで表示します(H で次のバージョンへ移動)。

## 現在できること

- ログイン画面: メールアドレスとパスワードの入力欄、ログイン ボタン、「自動ログイン」チェックボックス、QR コードの説明、タイトルバーのボタンに名前が付きます。
- アイコンだけのボタンには、アイコンに応じた名前が LINE 自身の表示言語(日本語、英語、タイ語、簡体字中国語、繁体字中国語)で付きます。
- キーボード: Tab と Shift+Tab ですべてのボタン、チェックボックス、リンクに読み上げ順に移動できます(ウィンドウの内容が先、タイトルバーのボタンが最後)。Space または Enter でフォーカスのあるコントロールを押します。LINE 自体は Tab でテキスト入力欄にしか移動できません。
- 移動に合わせて NVDA がフォーカスを追跡します(LINE は通常この通知を抑止していますが、ブリッジが再び有効にします)。
- チェックボックスは状態(「チェック」/「チェックなし」)を報告し、切り替えられます。
- 「スマートフォンでログイン >」のようなクリックできる文字はリンクになります。リンクで画面が切り替わると、新しい画面の最初の入力欄にフォーカスが移ります。
- ログイン画面に入ると説明(QR コードの説明など)を読み上げます。NVDA+B でもう一度読み上げます。
- LINE のウィンドウの影用ウィンドウと名前のないレイアウト グループは、オブジェクト ナビゲーションに表示されません。
- メイン ウィンドウ: サイドバーのタブ、トークのヘッダーとメッセージ バーのボタンに名前が付きます。トーク リストでは開いているトークは名前の前に「選択中」、名前、ピン留めしたトークは「ピン留め」、メンバー数、最後のメッセージ、時刻、未読数を読み上げます。友だちリストでは名前、メンバー数、グループの見出しを読み上げます。
- トーク リスト: 上下矢印、Page Up/Page Down、Home/End でトークを開かずにすばやく移動できます(トークを開くと LINE が最大 2 秒ほど止まるため)。Enter でトークを開き、メッセージ入力欄に移動します。右側のトークは Enter を押したときだけ切り替わります。
- メッセージ: 各メッセージを送信者(または「あなた」)、本文、時刻、既読の順に読み上げます。本文のないメッセージは種類を読み上げます: 写真、アルバム、動画、スタンプ、LINE 絵文字、ボイスメッセージ(長さ付き)、ファイル(名前とサイズ付き)、位置情報(住所付き)、通話(長さまたは状態付き)。リストに入ると最新のメッセージから始まります。同じトークで Tab または Shift+Tab で戻ると、最後に読んだメッセージに戻ります(Alt+M は常に最新のメッセージへ移動します)。上下矢印で 1 件ずつ、Page Up/Page Down でおよそ 1 画面分移動します。Home で読み込み済みの最も古いメッセージへ(LINE がさらに古いメッセージを読み込むので、もう一度 Home を押すとさらにさかのぼれます)、End で最新のメッセージへ移動します。Home または End をもう一度押すと、そのメッセージを再度読み上げます。LINE が前面にあるときは、ほかの人からの新着メッセージを通知します。
- トーク リスト パネルの Tab 順: 並べ替え、トークルームの表示/非表示(右側に開いているトークが表示中か非表示かを読み上げます。非表示にするとウィンドウがリストだけの幅になります)、トーク作成、広告、検索欄、トーク リスト(さらに Tab で開いているトークへ)。
- 並べ替え(トーク リストの検索欄の横): 選択中の項目(受信時間 / 未読)がわかります。選ぶとフォーカスが並べ替え後のリストの先頭のトークに移ります。「未読」では未読メッセージのあるトークが先頭に来るため、最新のトークがもともと未読なら、リストの上部は前と同じに見えることがあります。
- トーク内の検索(トークのヘッダーの検索ボタン): 語句を入力して Enter を押します。LINE はメッセージを絞り込まず、一致した最新のメッセージへトークを移動して一致件数を表示します。LINE MR は「検索結果 42 / 42」とそのメッセージを読み上げます。検索欄の上下矢印(または「前の検索結果」/「次の検索結果」ボタン)で古い / 新しい一致へ移動し、Enter で最新の一致からやり直します。Alt+M または Tab でメッセージに入ると一致したメッセージから始まるので、その前後を読めます。「検索結果を一覧表示」はすべての一致を別ウィンドウに表示し(送信者、日付、本文)、Enter でそのメッセージへトークを移動します。「日付へ移動」はカレンダーを開きます。
- 開いているトークの Tab 順: トークのヘッダーのボタン、トークのノート(ある場合)、「最新のメッセージへ移動」、メッセージ リスト、メッセージ入力欄、メッセージ バーのボタン(入力欄から外側へ: スタンプと絵文字、スクリーンショットのオプション、スクリーンショット、Keep、ファイルを添付)。
- コンテキスト メニュー: メッセージ上でアプリケーション キー(または Shift+F10)を押すと LINE のメニューが開き、最初の項目にフォーカスが移ります。上下矢印と Home/End で移動、Enter または Space で選択、Escape で閉じてメッセージに戻ります。グループとオープンチャットのほかの人のメッセージでは、最後の項目「<名前> のプロフィールを表示」で送信者のプロフィールが開きます(LINE MR が追加する項目で、画面には表示されません)。 メッセージ(日付、お知らせ、通話を除く)では、「リアクション」(これも LINE MR が追加する項目で、プロフィールの項目の前にあります)で LINE のリアクション一覧が開きます。左右矢印ですごい、いいね、ウケる、うらやましい、悲しい、その他のリアクションを移動し(名前はスマートフォンの LINE に合わせています。LINE は順番を変えることがあります)、Enter でリアクション、Escape で閉じます。すでに付けたリアクションは「選択中」と読まれ、もう一度選ぶと取り消せます。リアクション済みのメッセージでは項目が「リアクションを取り消す」になり、すぐに取り消します。リアクションの付いたメッセージは「リアクション: いいね」「いいね 3人」「リアクション: いいね、ウケる、計5人」のように種類を読み上げます(LINE は合計人数のみを表示し、種類ごとの人数は表示しません)。Keep メモのメッセージにはリアクションできません。
- 着信: ほかのアプリケーションで作業中でも、LINE MR が相手の名前とともに「着信」と読み上げます。LINE のウィンドウが前面にあるときは Alt+A で応答、Alt+D で拒否できます。ほかのアプリケーションからは NVDA+Shift+Control+A または NVDA+Shift+Control+D を使います(Alt+A と Alt+D はそのアプリケーションの通常の動作のままです)。通話中は、LINE で Alt+D、またはどこからでも NVDA+Shift+Control+D で通話を終了できます。LINE の着信がないときは、Alt+A と Alt+D は LINE での通常の動作をします。フォーカスは着信通知の「応答」ボタンに移ります(Tab で「拒否」へ、Enter または Space で押します)。通話中は通話ウィンドウのボタン(通話終了、マイクをオフ、ビデオ通話を開始、スピーカーをオフ)に名前が付き、テキスト(相手、通話時間)を読み上げます。 通話中、Windows はほかの音を小さくします(サウンド コントロール パネルの「通信」タブ)。LINE MR は NVDA の読み上げを通常の音量に保ちます(ほかのアプリケーションの通話にも適用されます)。
- 別ウィンドウで開くページを読み上げます: グループ名やメンバー数(例:「(5)」)をクリックするとメンバー リストが開き、メンバーからプロフィールを開けます。トーク メニューの「写真・動画」「リンク」「ファイル」は、トーク名の付いたウィンドウで開きます。そこでは矢印キーで写真・動画・リンクの一覧を移動できます(左右で 1 項目、上下で 1 行。Page Up/Page Down、Home、End も使えます)。写真や動画は「写真」または「動画」と読み上げ、Enter または Space で LINE のビューアーで開きます(リンクはブラウザーで開きます)。アプリケーション キーで LINE MR が追加したメニューが開きます: 開く、保存(写真・動画・ファイル。LINE が Windows のダイアログで保存先を尋ねます)、リンクをコピー、テキストをコピー(リンク)。LINE の動画プレーヤーでは再生/一時停止ボタンと再生位置スライダーを使えます: Tab で切り替え、Space または Enter で再生・一時停止、矢印キーで 5 秒、Page Up/Page Down で 30 秒移動、Home/End で先頭/末尾へ。位置は「00:12 / 00:38」のように読み上げます。3 つ目の再生速度(「1.0x」、0.2x～2.0x)は上下矢印で変更します。LINE は右矢印で次の写真・動画に移りますが、これらのキーはプレーヤーで使えます。下のサムネイル一覧は写真か動画かを読み上げます。ノート(グループやオープンチャットのノート ボタン):矢印キー、Home、End で投稿ごとに移動し、各投稿を「Peet、動画、コメント 2 件、8 分前」のように読み上げます。Enter または Space で投稿の写真や動画を同じビューアーで開き、フォーカスはプレーヤーの再生/一時停止から始まります。Escape で元の投稿に戻ります。投稿でアプリケーション キーを押すとメニューが開きます: 開く、名前を付けて保存...(LINE のビューアーが開き、Windows が保存先を尋ねます)、テキストをコピー(テキストのある投稿)、その他のオプション(LINE のメニュー: 重要なノートに設定、編集、削除)。ビューアーでは Ctrl+S でも保存できます。フォーカスはページの最初のコントロールから始まり、ページの文字を読み上げます。メイン ウィンドウ内で開くページにもフォーカスが移ります。
- スタンプと絵文字(メッセージ バーのボタン): パッケージ一覧は「最近使用」とパッケージ名を読み上げます(LINE は一覧に画像しか提供しないため、名前はスタンプ画面の編集ボタンで開く「マイスタンプ」から読み取ります。名前がまだないときやパッケージ数が変わったときは、スタンプ画面を開いたときに LINE MR が約 1 秒間自動で開いて戻ります)。左右矢印で移動、Enter でパッケージを開いて最初のスタンプへ移動します。スタンプは「スタンプ 1」…と読み上げ(LINE は名前を提供しません)。矢印キーで一覧を移動します。最初の Enter または Space でスタンプや絵文字を選択し(「選択中、もう一度押すと送信」)、LINE のプレビューを音付きで再生します(サウンド付きスタンプ)。もう一度押すと送信し、スタンプ画面を閉じてメッセージ入力欄に戻ります。トークを上にスクロールしたときに出る丸い下矢印は「最新のメッセージへ移動」と読み上げます。
- そのほかのウィンドウ: 設定(その他 > 設定。セクションとサブセクションはラジオボタン、コンボボックスにはラベルが付きます)、プロフィール設定、アルバムとノート、友だち検索、トーク作成(トークリストの下のボタン: トーク、グループトーク、オープンチャット)。トーク作成 / グループ作成の友だちリストでは友だちはチェックボックスです。上下矢印、Page Up/Page Down、Home/End で全員の間を移動、Space でチェック、Tab でリストを出て選んだ友だち(「<名前> を取り除く」)と「次へ」へ、Shift+Tab で最後に読んだ友だちに戻ります。グループのプロフィール設定ページには、プロフィール画像を変更、グループ名を編集、「メンバーが自動で参加」スイッチ(チェックボックス)があります。オープンチャット作成では、まずオープンチャットの名前、キーワード、カテゴリーを、(「次へ」の後に)そのオープンチャットでのニックネームを入力します。入力欄はページの目的を読み上げ、欄の中の × は「テキストをクリア」です。プロフィール画像を変更 > テキストでプロフィールを作成では、色は番号と色名の付いたチェックボックス(「色 4: 明るいピンク」)で、Space で選びます(チェック)。文字の色 / 背景色で色を変える対象を選び、フォント一覧は「フォント」です。投票は Web ページとして開き、ブラウズ モードで読み上げます。
- 画像メッセージ(銀行などの公式アカウントのカード)は文字が画像に描き込まれているため、LINE は読み上げる文字を提供しません。そのため「写真またはスタンプ」と報告されます。そのメッセージで NVDA+R を押すと、Windows OCR で文字を読み取れます。LINE がカードをダウンロードできなかった場合は「読み込めません」と「再試行」ボタンが表示され、それが読み上げられます。

## コマンド

| コマンド | 動作 |
|---|---|
| Alt+1 / Alt+2 / Alt+3 | 友だち / トーク / 友だち追加 タブ |
| Alt+C | トーク リストへ移動(必要ならまずトーク タブに切り替え) |
| Alt+L | トーク リストまたは友だちリスト(表示されている方)へ移動 |
| Alt+F | トーク リストまたは友だちリストの検索欄へ移動 |
| Alt+M | 開いているトークのメッセージへ移動 |
| Alt+I | 開いているトークのメッセージ入力欄へ移動 |
| NVDA+Alt+1 … NVDA+Alt+9 | 最近のメッセージを読み上げ(1 = 最新) |
| LINE で Alt+A、どこからでも NVDA+Shift+Control+A | LINE の着信に応答 |
| LINE で Alt+D、どこからでも NVDA+Shift+Control+D | LINE の着信を拒否。通話中は通話を終了 |
| NVDA+Shift+Control+L | LINE MR ブリッジが動作しているか報告(必要ならインストールを提案)。2 回押すと開発者向けのレポートをクリップボードにコピー |

コマンドは NVDA メニュー、設定、入力ジェスチャー、カテゴリ「LINE MR」で変更できます。

| 場所 | キー |
|---|---|
| どこでも | Tab / Shift+Tab でコントロール間を移動。Space または Enter でボタン、チェックボックス、リンクを押す |
| トーク リスト | 上下矢印、Page Up/Page Down、Home/End でトークを開かずに移動。Enter でトークを開き、メッセージ入力欄へ移動 |
| メッセージ | 上下矢印: 前 / 次のメッセージ。Page Up/Page Down: およそ 1 画面分。Home: 読み込み済みの最も古いメッセージ(もう一度: さらに古いメッセージを読み込む)。End: 最新のメッセージ。アプリケーション キーまたは Shift+F10: メッセージのメニュー。Enter または Space: 長いメッセージの全文を表示(ワープロのように読めます: 上下矢印は LINE が表示する行ごとに移動し、改行は書き手が改行した所だけにあります。Control+上下矢印で段落ごとに移動。Escape で戻ります)、ボイスメッセージを再生または一時停止、サウンド付きスタンプの音をもう一度再生、写真や動画を LINE のビューアーで開く(Tab でボタンとサムネイルを移動、Escape で閉じてトークに戻る)、ファイル(PDF、Word など)をそのアプリで開く、リンク(メッセージ内の最初の Web アドレス)を Web ブラウザーで開く |
| メッセージ メニュー | 上下矢印、Home/End で移動。Enter または Space で選択。Escape で閉じてメッセージに戻る |
| トーク内の検索欄 | Enter: 検索(最新の一致からやり直し)。上下矢印: 古い / 新しい一致。LINE MR が何件目かとメッセージを読み上げます |
| 検索結果ウィンドウ | 上下矢印で移動。Enter でトーク内のそのメッセージへ |

## LINE MR が動作しない場合

LINE で NVDA+Shift+Control+L を押してください。LINE MR が問題を報告し、可能であれば修正を提案します。

- **ブリッジがインストールされていない / 古いブリッジがインストールされている / LINE の再起動が必要:** **はい** を選ぶと、LINE がいったん終了し、ブリッジを読み込んだ状態で再び起動します。LINE のウィンドウを閉じても LINE は終了しません(通知領域で動作し続けます)。そのため、ブリッジのインストール前に起動した LINE は、再起動するまでブリッジなしで動作します。LINE に戻ると LINE MR がもう一度尋ねます(「いいえ」の後は 10 分後、NVDA+Shift+Control+L ならすぐに)。
- **LINE がすべてのユーザー向けにインストールされている**(Program Files): LINE のフォルダーにブリッジを追加するため、Windows が管理者の許可を求めます。許可してください。
- **LINE が LINE MR ブリッジなしで起動した:** インストール後、LINE MR は LINE が実際にブリッジを読み込んだか確認します。読み込まれていない場合は、Windows またはウイルス対策ソフトがブロックしています。Windows 11 の **Smart App Control** がオンだと、ブリッジ(署名のないファイル)がブロックされ、LINE MR は動作できません。Windows セキュリティの「アプリとブラウザーの制御」でオフにできます(Windows を再インストールしない限り再びオンにはできません)。ウイルス対策ソフトが `line_a11y.dll` を削除またはブロックすることもあります。ファイルを許可してから、LINE で NVDA+Shift+Control+L をもう一度押してください。
- **この LINE のバージョンには対応していない:** LINE が古すぎてブリッジを読み込めません。LINE を更新してください。
- **ボタンは読めるが、メッセージが「写真またはスタンプ」と読まれる、または読まれない:** LINE が 2 回続けて予期せず終了したため、LINE を安定させるためにブリッジがメッセージ内容の読み取りを止めています。LINE を通常の方法で終了し(メニューまたは通知領域から)、再び起動してください。

問題を報告するには、LINE で NVDA+Shift+Control+L を **2 回** 押してください。LINE MR が短いレポートをクリップボードにコピーします(NVDA、Windows、LINE、Qt のバージョン、LINE のインストール場所、ブリッジの状態と起動時のログ。トークの内容は含まれず、ユーザー フォルダーは `%USERPROFILE%` に置き換えられます)。メッセージや GitHub の issue に貼り付けてください。

## ブリッジの仕組み

ブリッジは `line_a11y.dll` という Qt のプラットフォーム テーマ プラグインで、`%LOCALAPPDATA%\LINE\bin\current\platformthemes` に置かれます。LINE の通話プログラム(着信と通話ウィンドウを表示する `LineCall.exe`)用のコピーは `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<バージョン>\platformthemes` に、LINE の写真・動画ビューアー(`LineMediaPlayer.exe`)用のコピーは `%LOCALAPPDATA%\LINE\Data\plugin\LineMediaPlayer\<バージョン>\platformthemes` に置かれます。LINE の Qt が起動時にこれを読み込みます。ブリッジはテーマを返さないので(LINE の見た目はまったく変わりません)、LINE 独自のウィジェットにアクセシビリティ インターフェイスを追加するだけです。文字は各ウィジェットが描画する内容を記録して読み取るため、LINE の内部メモリ配置には依存しません。LINE のファイルは一切変更しません。削除するには、これらの DLL を削除してください。

ログ: `%LOCALAPPDATA%\LineMR\logs\bridge.log`

LINE MR は独立したプロジェクトであり、LY Corporation / LINE とは提携しておらず、承認も受けていません。
