# LINE MR (Line Mai Roo) for NVDA

LINE MR 让 [LINE for Windows](https://line.me) 可以配合 NVDA 使用。

LINE 自行绘制按钮和文字,因此它本身几乎不向屏幕阅读器提供任何信息:按钮没有名称,文字也无法朗读。LINE MR 在 LINE 中加入一个小型无障碍桥接组件,为 LINE 的控件提供名称、角色和操作,并提供一个 NVDA 应用模块,整理 NVDA 朗读的内容。

## 安装

**推荐:安装 [Microsoft Store 版 LINE](https://apps.microsoft.com/detail/XPFCC4CD725961)**(LY Corporation 发布的“LINE Desktop”;也可以在 Microsoft Store 应用中搜索“LINE”)。LINE MR 基于 Microsoft Store 版开发和测试,因此兼容性最好。它会把 LINE 安装到 `%LOCALAPPDATA%\LINE` 并自动保持更新。从其他来源获得的 LINE 可能安装在别的位置或是不同的版本,桥接组件可能无法安装或无法工作。

1. 安装本插件并重新启动 NVDA。
2. 启动 LINE(或切换到 LINE)。LINE MR 会询问是否将桥接组件安装到 LINE 中,请选择 **是**。LINE 会关闭并带着桥接组件重新启动。

LINE 更新后可能需要重新安装桥接组件;LINE MR 会自动发现并再次询问。

## 更新 LINE MR

NVDA 启动时,LINE MR 会在 GitHub 上检查是否有新版本。如果有,会弹出对话框,提供 **立即更新**、**稍后** 或 **跳过此版本**。选择“立即更新”会下载新版本并交给 NVDA,NVDA 会请你确认安装,然后重新启动 NVDA。要关闭检查或立即检查:NVDA 菜单,选项,设置,类别“LINE MR”。命令“检查 LINE MR 的新版本”(默认没有按键)可以在“按键与手势”中分配按键。

## 目前可以做到的

- 登录窗口:邮箱和密码输入框、登录按钮、“自动登录”复选框、二维码说明以及标题栏按钮都有名称。
- 只有图标的按钮会根据图标获得名称,使用 LINE 自身的界面语言(简体中文、繁体中文、英语、泰语或日语)。
- 键盘:Tab 和 Shift+Tab 可以按朗读顺序到达每个按钮、复选框和链接(先是窗口内容,最后是标题栏按钮);空格或回车按下当前焦点所在的控件。LINE 本身只允许用 Tab 到达文本输入框。
- 移动时 NVDA 会跟随焦点(LINE 通常会屏蔽这些通知,桥接组件将其重新开启)。
- 复选框会报告并切换状态(“选中”/“未选中”)。
- “使用智能手机登录 >”这类可点击的文字会作为链接;当它切换界面后,焦点会移到新界面的第一个输入框。
- 进入登录窗口时会朗读其说明(例如二维码说明);按 NVDA+B 可再次朗读。
- LINE 用于窗口阴影的窗口和没有名称的布局分组不会出现在对象导航中。
- 主窗口:侧边栏标签、聊天标题栏和消息栏的按钮都有名称。聊天列表朗读名称、成员数、最后一条消息、时间和未读数;好友列表朗读名称、成员数和分组标题。
- 聊天列表:上下方向键、Page Up/Page Down 和 Home/End 可以快速浏览聊天而不打开它们(打开聊天会让 LINE 停顿最多约两秒);回车打开聊天并移到其消息输入框。右侧的聊天只有在按回车时才会切换。
- 消息:每条消息按发送者(或“你”)、内容、时间和已读状态朗读;没有文字的消息会说明其类型:照片、相册、视频、贴图、LINE 表情、语音消息(含时长)、文件(含名称和大小)、位置(含地址)或通话(含时长或状态)。进入列表时(Tab、Shift+Tab 或 Alt+M)从最新的消息开始。上下方向键移动一条消息,Page Up/Page Down 约移动一屏;Home 到已加载的最早消息(LINE 随后会加载更早的消息,再按 Home 可继续往前),End 到最新消息;再次按 Home 或 End 会重新朗读该消息。LINE 在前台时,会播报他人发来的新消息。
- 聊天列表面板中的 Tab 顺序:排序、显示或隐藏聊天列表、创建聊天、广告、搜索框,然后是聊天列表(再按 Tab 进入已打开的聊天)。
- 已打开聊天中的 Tab 顺序:聊天标题栏按钮、聊天的记事本(如果有)、“滚动到最新消息”、消息列表、消息输入框,然后是消息栏按钮(从输入框向外:贴图和表情、截图选项、截图、Keep、附加文件)。
- 上下文菜单:在消息上按应用程序键(或 Shift+F10)会打开 LINE 的菜单,焦点在第一个项目上;上下方向键和 Home/End 移动,回车或空格选择,Esc 关闭并返回消息。
- 来电:即使你在其他应用程序中工作,LINE MR 也会朗读“来电”和来电者的名字。在任何应用程序中按 Alt+A 接听,按 Alt+D 拒绝(没有 LINE 来电时,这些按键在该应用程序中保持原有功能;NVDA+Shift+Control+A / D 同样可用)。通话期间,当 LINE 窗口在前台时按 Alt+D 结束通话(在任何位置可按 NVDA+Shift+Control+D)。焦点会移到来电通知的“接听”按钮(按 Tab 到“拒绝”;回车或空格按下)。通话期间,通话窗口的按钮(结束通话、关闭麦克风、开始视频通话、关闭扬声器)都有名称,并会朗读其文字(对方、通话时长)。
- 在独立窗口中打开的页面会被朗读:点击群组名称或其成员数(例如“(5)”)会打开成员列表;从成员可以打开其个人资料;聊天菜单中的“照片和视频”“链接”和“文件”会在以聊天名称命名的窗口中打开。焦点从页面的第一个控件开始,并会朗读页面文字。在主窗口内打开的页面也会获得焦点。
- 其他窗口:设置(更多 > 设置;其各部分和子部分为单选按钮,组合框带有标签)、个人资料设置、相册和记事本、搜索好友,以及创建群组(好友为复选框:按空格勾选)。投票以网页形式打开,在浏览模式下朗读。
- 图片消息(银行等官方账号发送的卡片)的文字是画在图片里的,LINE 不提供可朗读的文字,因此会报告为“照片或贴图”。在这类消息上按 NVDA+R,可用 Windows OCR 识别其文字。如果 LINE 无法下载卡片,会显示“无法加载”和“重试”按钮,你听到的就是这些内容。

## 命令

| 命令 | 操作 |
|---|---|
| Alt+1 / Alt+2 / Alt+3 | 好友 / 聊天 / 添加好友 标签 |
| Alt+C | 移到聊天列表(如有需要先切换到聊天标签) |
| Alt+L | 移到聊天列表或好友列表(当前显示的那个) |
| Alt+F | 移到聊天列表或好友列表的搜索框 |
| Alt+M | 移到已打开聊天的消息 |
| Alt+I | 移到已打开聊天的消息输入框 |
| NVDA+Alt+1 … NVDA+Alt+9 | 朗读最近的消息(1 = 最新) |
| Alt+A(或 NVDA+Shift+Control+A) | 接听 LINE 来电(在任何应用程序中都可用) |
| Alt+D(或 NVDA+Shift+Control+D) | 拒绝 LINE 来电(在任何应用程序中都可用);通话期间结束通话(Alt+D 需 LINE 窗口在前台,NVDA+Shift+Control+D 在任何位置) |
| NVDA+Shift+Control+L | 报告 LINE MR 桥接组件是否在运行(并提供安装);按两次将给开发者的报告复制到剪贴板 |

可以在 NVDA 菜单,选项,按键与手势,类别“LINE MR”中修改命令。

## 如果 LINE MR 不工作

在 LINE 中按 NVDA+Shift+Control+L。LINE MR 会说明问题所在,并在可能时提供修复:

- **桥接组件未安装 / 安装的是旧版桥接组件 / 需要重新启动 LINE:** 选择 **是**,LINE 会关闭并带着桥接组件重新启动。关闭 LINE 的窗口并不会退出 LINE(它会继续在通知区域中运行),因此在安装桥接组件之前启动的 LINE 会一直在没有桥接组件的情况下运行,直到重新启动;回到 LINE 时 LINE MR 会再次询问(选择“否”后 10 分钟再问,按 NVDA+Shift+Control+L 则立即询问)。
- **LINE 是为所有用户安装的**(在 Program Files 中):Windows 会请求管理员权限,以便把桥接组件加入 LINE 的文件夹。请允许。
- **LINE 启动时没有加载 LINE MR 桥接组件:** 安装后,LINE MR 会检查 LINE 是否真的加载了桥接组件。如果没有,说明被 Windows 或杀毒软件阻止了。Windows 11 的 **智能应用控制** 开启时会阻止桥接组件(文件没有签名),LINE MR 无法工作;可以在 Windows 安全中心的“应用和浏览器控制”中关闭(关闭后除非重新安装 Windows,否则无法再次开启)。杀毒软件也可能删除或阻止 `line_a11y.dll`:请允许该文件,然后在 LINE 中再次按 NVDA+Shift+Control+L。
- **LINE MR 不支持此版本的 LINE:** LINE 版本太旧,无法加载桥接组件。请更新 LINE。
- **按钮可以朗读,但消息被读成“照片或贴图”或无法朗读:** LINE 连续两次意外关闭,为了让 LINE 保持稳定,桥接组件暂停读取消息内容。请正常退出 LINE(从菜单或通知区域),然后再启动。

要报告问题,请在 LINE 中按 **两次** NVDA+Shift+Control+L。LINE MR 会把一份简短的报告复制到剪贴板(NVDA、Windows、LINE 和 Qt 的版本,LINE 的安装位置,桥接组件的状态和启动日志;不含聊天内容,你的用户文件夹会替换为 `%USERPROFILE%`)。把它粘贴到你的消息或 GitHub issue 中。

## 桥接组件的工作原理

桥接组件是 `line_a11y.dll`,一个放在 `%LOCALAPPDATA%\LINE\bin\current\platformthemes` 中的 Qt 平台主题插件;LINE 的通话程序(显示来电和通话窗口的 `LineCall.exe`)使用的副本放在 `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<版本>\platformthemes` 中,LINE 的照片和视频查看器(`LineMediaPlayer.exe`)使用的副本放在 `%LOCALAPPDATA%\LINE\Data\plugin\LineMediaPlayer\<版本>\platformthemes` 中。LINE 的 Qt 在启动时加载它;它不返回任何主题(因此 LINE 的外观完全不变),只为 LINE 的自定义控件添加无障碍接口。它通过记录每个控件绘制的内容来读取文字,因此不依赖 LINE 的内部内存布局。不会修改任何 LINE 文件;要移除它,删除这些 DLL 即可。

日志:`%LOCALAPPDATA%\LineMR\logs\bridge.log`。

LINE MR 是一个独立项目,与 LY Corporation / LINE 无关联,也未获其认可。
