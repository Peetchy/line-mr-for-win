# LINE MR 新功能

## 版本 0.6.1

- LINE MR 自己命名的按钮,如果 LINE 有对应的文字,现在使用 LINE 自己的文字和语言:聊天列表中的“收拢聊天”/“展开聊天”(原为“显示或隐藏聊天室”)和“创建聊天”。
- 从消息输入框按 Shift+Tab 回到消息时,不会再在片刻后跳到最新消息;方向键、Alt+R、Alt+T 等消息按键作用于最后读到的消息(由 wengweng0312 贡献,#23)。

## 版本 0.6.0

### 快捷键
- 新增:在消息列表中按 Alt+Shift+R 打开所选消息的回应(菜单中的“回应”);如果已经回应过,则打开以便取消。
- 使用字母或数字的命令 (Alt+C、Alt+M、Alt+1 等) 在泰文或其他非拉丁字母键盘布局下也能使用:按英文键盘上相同位置的键计算,无需先切换到英文。
- 消息列表中的 Alt+T 现在用于翻译所选消息（LINE 消息菜单中的“翻译”）；语音消息转文字改为 Alt+Shift+T。
- Alt+C、Alt+L、Alt+F 和 Alt+1 / Alt+2 / Alt+3 现在在单独窗口中打开的聊天里也可用:LINE 主窗口会切换到前面,焦点移到那里。在隐藏了聊天室的主窗口中,Alt+M 和 Alt+I 会移到聊天窗口。

### 语音消息转文字
- 视频也可以转为文字:在聊天中的视频(菜单:“将视频语音转为文字”)、“照片和视频”、笔记或 LINE 的查看器中按 Alt+Shift+T。LINE 会把视频保存到 LINE MR 的文件夹,完成后删除该文件。超过 5 分钟的语音消息或视频会先询问,因为转换在本机上进行,可能需要较长时间。
- 转文字始终使用所选消息的文件:LINE 把它保存到 LINE MR 的文件夹(%LOCALAPPDATA%\LineMR\media;“另存为”窗口会一闪而过),得到文字后删除该文件,不会播放。保存后 LINE 在该消息的菜单中显示“打开文件夹”而不是“另存为”;文件删除后 LINE MR 会在后台按下“打开文件夹”(不会打开任何东西),菜单便恢复为“另存为”。以前 LINE MR 可能从 LINE 的缓存中取到另一条同样长度的消息,并显示它的文字。LINE 无法保存的语音消息(已过期)仍像以前一样播放并录音。
- 语音消息或视频的文字现在在转换过程中就会出现(每 30 秒的声音),期间可以阅读和编辑;新的行添加在末尾,不移动光标,你的修改会保留。
- 超过 30 秒的录音在转换前会在停顿处切分,不再每 30 秒重复或漏掉词语。“复制”在文字完整后出现。语音模型列表来自 GitHub 上的 LINE MR 仓库:新模型无需更新插件即可出现在设置和对话框中。
- 新功能：在语音消息上按 Alt+Shift+T（或在其菜单中选择“将语音消息转为文字”），在本机将其转为文字；文字在窗口中显示，可阅读、编辑和复制。默认关闭：在 NVDA 设置的 LINE MR 类别中开启后，会一次性下载在那里选择的语音模型。共 6 个模型：Typhoon Whisper Turbo（874 MB，默认：最适合泰语，也适用于英语和日语，在 Typhoon 模型中内存最少）、Typhoon Whisper Medium 和 Large v3（仅限泰语；Large v3 最准确，但非常慢），以及 OpenAI 的 Whisper Small、Medium、Large v3 Turbo（多种语言）；也可用“选择模型文件”使用您自己的 whisper.cpp 模型，LINE MR 会在使用前检查。每次转换前的对话框会询问模型和语言。请参阅指南“语音消息转文字”。

### 保存消息
- 新功能：在消息列表中按 Ctrl+S 保存所选消息。照片、视频、文件和语音消息：使用 LINE 的“另存为”（LINE 会询问保存位置）。文字消息（完整保存，长消息也一样）、位置和联系人：保存为文本文件（.txt），LINE MR 会询问保存位置。贴图、通话、日期和通知：LINE MR 会告知无法保存。在其他位置 Ctrl+S 照常工作，可在 NVDA 的按键与手势中更改。

### 照片和视频
- 现在可以一次保存或分享多张照片和多个视频 (#9):在聊天的“照片和视频”窗口(聊天菜单)中,按空格勾选光标所在的项目,NVDA 会读出是否已勾选;按 Tab 可到达网格下方 LINE 的栏(已选数量、分享、发送到 Keep 备忘录、下载、取消)。下载会询问文件夹;取消会取消全部勾选并返回网格。回车仍然打开项目。聊天中发送的相册里的照片也在这里:LINE 本身也只能在这个窗口中一次保存多张照片。

### 聊天列表
- 隐藏聊天室时(显示或隐藏聊天室按钮),回车或空格会立即在单独的窗口中打开聊天并移到其消息输入框。以前第一次按只会选中聊天,需要再按一次。聊天列表中空格现在与回车相同。尚未打开任何聊天时,显示或隐藏聊天室按钮也会正确报告状态。
- 新功能:在聊天列表中按 Shift+回车,会在单独的窗口中打开聊天(与聊天菜单中的“在新窗口中打开”相同),并移到其消息输入框。
- 未读数读作“3 条未读消息”（原为“3 条未读”），仍在聊天行的末尾。
- 群组和社群会在聊天名称后读出类型：“DHCB, 群组, 37 名成员, ...”、“English talk, 社群, ...”（#5）。官方账号无法与好友区分：LINE 没有提供可区分的信息。

### 设置
- NVDA 设置的“LINE MR”类别显示桥接组件是否在运行,并有按钮可断开它(按原样使用 LINE,不带 LINE MR)或重新连接。两种情况下 LINE 都会重新启动。
- 在 NVDA 的插件商店中移除 LINE MR 时,现在也会从 LINE、其通话程序和照片查看器中移除桥接组件,并删除 LINE MR 的文件夹 `%LOCALAPPDATA%\LineMR`。正在运行的 LINE 会继续使用桥接组件,直到退出。

### 消息
- 长消息和部分收到的消息的菜单中没有“回应”：它们被误认为通知，已修正（#3）。
- 用回车打开聊天时保持 LINE 的位置(例如第一条未读消息),不再跳到最新的消息;从消息输入框按 Shift+Tab 回到消息时停留在屏幕上(最后阅读的消息仍可见时停在该消息,否则停在屏幕上的第一条)。由 wengweng0312 贡献(#20)。
- 在消息列表中,Alt+R 回复所选消息并移到消息输入框,Delete 删除,Shift+Delete 撤回(即 LINE 消息菜单中的项目;LINE 的确认由你自己回答)。在其他地方这些键照常使用,可在 NVDA 的输入手势中更改(由 wengweng0312 贡献)。
- 在消息菜单中选择“回复”会移到消息输入框(由 wengweng0312 贡献)。
- 回复时可以到达消息输入框上方的栏:在消息输入框按 Shift+Tab 会到“取消回复”和“转到原消息”。取消后回到消息输入框。
- NVDA 设置的“LINE MR”类别中的新选项“在一对一聊天中显示对方姓名”:在对方的消息前读出对方的名字(默认关闭)。LINE 没有显示时间的你自己的长消息也会读作你的(由 wengweng0312 贡献)。
- 在聊天列表中按 Enter 会停留在所打开聊天的消息输入框:LINE 有时在聊天加载完成后把焦点移到消息列表。在打开的聊天中,Tab 总是依次到消息列表、消息输入框,然后是其下方的按钮。
- 群聊中的 @ 提及:输入 @ 后,上下箭头读出 LINE 建议的成员,继续输入可筛选,按 Enter 选择。以前箭头键在这里不起作用(由 wengweng0312 贡献)。在消息输入框中,所选成员读作“@姓名”(以前 NVDA 什么也不读)。
- 消息读出 LINE 自己的文本(LINE 26.6 及更高版本):每条消息都有发送者和时间,回复完整,文件名完整,也包括不在屏幕上的消息。LINE 没有说明的部分由 LINE MR 补充:你自己的消息前的“你”、贴图和通话以及心情反应(由 wengweng0312 贡献)。桥接组件读取的长度(通话,以及没有 LINE 文本的语音消息和视频)读作“7秒”“10分钟54秒”,而不是“00:07”“10:54”。
- 消息也会读出 LINE 自身文字中没有的内容:文件大小和下载期限、链接预览的标题、地址前的“位置”、“联系人”及其名称,以及用“相册”代替“照片”。回复先读回复内容:“X, 回复 Y：<回复>, 原消息：<引用>”。在 Keep 备忘录中每条消息都读作“你”;并能识别日文和中文 LINE 的时间与已读状态,因此在这些语言中你自己的消息也读作“你”。
- NVDA 设置的“LINE MR”类别中的新选项“仅在发送者改变时朗读发送者姓名”(默认关闭):同一人的连续消息直接从内容开始。

## 版本 0.5.5

### 更新
- 从 NVDA 插件商店安装时,更新交给插件商店:LINE MR 不再检查 GitHub,设置中也会说明。

### 焦点突出显示
- 为了低视力用户:带黑边的黄色框显示 LINE 中哪个控件获得焦点(也包括聊天、消息和菜单项)。可以在 NVDA 设置的 LINE MR 类别中更改颜色和宽度,或将其关闭。

### 修复
- 在 NVDA 2025.4 或更早版本(32 位 NVDA)中,LINE MR 已经可用却反复要求重新启动 LINE。现在能正确识别 LINE 已在运行 LINE MR。
- 在消息输入框和其他文本框中,上/下箭头朗读屏幕上显示的行:自动换行的长段落逐行朗读,不再每行都重复整段;空行朗读为“空白”,不再朗读上一行。
- 在消息输入框中逐行阅读时,上/下箭头不再使焦点移走(移到上方 LINE 的贴图和表情推荐)。
- 在已加载的最旧消息上按上箭头,LINE 会加载更早的消息,并可继续向上(由 wengweng0312 贡献)。
- 用键盘更改的设置复选框(例如 通知 > 显示消息内容)现在会被保存(由 wengweng0312 贡献)。
- 能识别 LINE 分成几块绘制的语音消息,按 Enter 或空格即可播放(由 wengweng0312 贡献)。
- 繁体中文 LINE:已读标记(已讀)和时间(下午 2:49)在消息末尾朗读,内容为“已讀”的收到消息不会被当作已读标记(由 Keyang556 贡献)。

## 版本 0.5.4

### 长消息
- 在长消息的全文(“查看更多”)中,NVDA 只在作者自己换行的地方说“换行”,与 Word 一样。上下方向键仍按 LINE 显示的行移动。

### 消息
- 一些带链接的消息(例如 YouTube 链接)被读成"通话"。现在只有 LINE 的通话消息读作"通话";以前读作"照片或贴图"的视频通话也读作"通话"。

### 聊天列表
- 当前打开的聊天在名称前读“已选择”,置顶的聊天在名称后读“已置顶”。

### 创建聊天(聊天、群聊、开放聊天)
- 选择好友页面打开时焦点在搜索框。上下方向键、Page Up/Page Down 和 Home/End 在所有好友之间移动,按空格勾选。按 Tab 离开列表,前往已选好友(“移除 <名字>”)和“下一步”。按 Shift+Tab 返回最后朗读的好友。
- 群组资料设置页面的按钮都有名称:更换头像、更换背景图片和编辑群组名称。“成员自动加入”是复选框,按空格切换。
- 创建开放聊天:关键词框和类别都有名称,框内的 X 读作“清除文本”。按“下一步”后,焦点移到“你在此开放聊天中的昵称”,并朗读该页面的用途。
- 创建文字头像(更换头像 > 创建文字头像):颜色是带编号和颜色名的复选框(“颜色 4: 浅粉色”),按空格选择。“文字颜色 / 背景颜色”决定颜色改变的对象。字体列表名为“字体”。

### 记事本
- 朗读记事本(群组和开放聊天)中的帖子:作者、照片或视频、回应和评论数以及时间。方向键逐条移动帖子;按回车在 LINE 的视频播放器中播放帖子的视频(焦点在播放/暂停),按 Esc 返回帖子。
- 在帖子上按应用程序键打开菜单:打开、另存为...、复制文字和更多选项(LINE 的菜单)。在 LINE 的查看器中按 Ctrl+S 保存照片或视频。

### 设置
- 在 NVDA 设置的 LINE MR 类别中新增了这个“新功能”按钮。

## 版本 0.5.3
- 消息菜单(应用程序键)新增“回应”,并朗读消息上的回应。
- 贴图包按名称朗读。第一次按回车选择贴图或表情并预览,第二次按回车发送。
- 在群组中,消息菜单有“查看 <名字> 的个人资料”。朗读聊天内搜索的结果。
- 用方向键浏览聊天的照片、视频、链接和文件,按回车打开。在视频播放器中,按空格播放或暂停,方向键快进或快退。
- 通话时 LINE 降低其他声音,NVDA 的音量保持不变。视频通话窗口朗读摄像头和麦克风是否开启。

## 版本 0.5.2
- 在含有链接的消息上按回车,在浏览器中打开链接。
- 在语音消息、文件或照片上按应用程序键,打开该消息自己的菜单。
- 按 Tab 回到消息列表时,回到最后朗读的消息。逐行朗读长消息更快。

## 版本 0.5.1
- 按回车或空格打开消息的内容(语音、视频、照片、文件)。
- LINE 的照片和视频查看器中也可使用。聊天文件夹标签可以筛选列表。
- 可以在更多电脑上安装。按两次 NVDA+Shift+Control+L 复制给开发者的报告。

## 版本 0.5.0
- 像记事本一样逐行朗读长消息。
- Alt+F 移到搜索框。Alt+A / Alt+D 接听或拒绝来电。
- 支持日语、简体中文和繁体中文。

## 版本 0.4.5
- 完整朗读长消息。更改了聊天列表面板的 Tab 顺序。

## 版本 0.4.4
- 根据 LINE 自己的图标识别视频、文件、位置和贴图。

## 版本 0.4.3
- 提示来电并可以接听。语音消息与时长一起朗读。Alt+C 移到聊天列表。
