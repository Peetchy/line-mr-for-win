# LINE MR (Line Mai Roo) for NVDA

LINE MR makes [LINE for Windows](https://line.me) usable with NVDA.

LINE draws its own buttons and text, so on its own it exposes almost nothing to screen readers: buttons have no names and texts cannot be read. LINE MR adds a small accessibility bridge to LINE that gives LINE's controls names, roles and actions, and an NVDA app module that tidies up what NVDA reads.

## Installing

**Recommended: install [LINE from the Microsoft Store](https://apps.microsoft.com/detail/XPFCC4CD725961)** ("LINE Desktop" by LY Corporation; in the Microsoft Store app you can also search for "LINE"). LINE MR is developed and tested with the Microsoft Store version, so it gives the best compatibility. It installs LINE into `%LOCALAPPDATA%\LINE` and keeps it up to date. LINE from other sources may be installed somewhere else or be a different build, and the bridge may not install or work there.

1. Install the add-on and restart NVDA.
2. Start LINE (or switch to it). LINE MR asks to install its bridge into LINE. Choose **Yes**. LINE closes and starts again with the bridge.

After a LINE update the bridge may have to be installed again; LINE MR notices and asks again.

## Updating LINE MR

When NVDA starts, LINE MR checks GitHub for a newer release. If there is one, a dialog offers **Update now**, **Later** or **Skip this version**. Update now downloads the new version and hands it to NVDA, which asks you to confirm the installation and then to restart NVDA. To turn the check off or check right away: NVDA menu, Preferences, Settings, category "LINE MR". The command "Checks for a newer version of LINE MR" (no key by default) can be given a key in Input gestures. If you installed LINE MR from the NVDA Add-on Store, the Store offers the updates and LINE MR does not check GitHub.

The same category has a **What's new** button: it lists what changed in each version, in a window you read like a web page (H moves to the next version).

## Using LINE without LINE MR

To use LINE as it is, without LINE MR's changes (for example to compare, or when LINE's own accessibility is enough for you): NVDA menu, Preferences, Settings, category "LINE MR". The **Bridge** field tells whether the bridge is running, and the button next to it offers the opposite: **Disconnect bridge** removes the bridge from LINE (also from its call window and photo viewer), **Connect bridge** installs it again. Both close LINE and start it again, so a call in progress ends. While the bridge is disconnected, LINE MR does not ask to install it, and NVDA+Shift+Control+L says that it is disconnected.

## Focus highlight

For low-vision users, LINE MR draws a yellow frame with a black outline around the control that has the focus in LINE, its call windows and its photo viewer: the button, field, chat, message or menu item NVDA reads. It follows the keyboard, also through the chat list, the messages and menus, and is hidden while another application is in front. To turn it off or change its colour (yellow, orange, red, green, blue, white) and width: NVDA menu, Preferences, Settings, category "LINE MR". LINE applies the change within a second, also when NVDA is not running.

## What works now

- Login window: email and password fields, the log-in button, the "log in automatically" checkboxes, the QR-code instructions and the title bar buttons are named.
- Icon-only buttons are named from their icons, in LINE's own language (English, Thai, Japanese, Simplified or Traditional Chinese).
- Keyboard: Tab and Shift+Tab reach every button, checkbox and link in reading order (window content first, title-bar buttons last); Space or Enter presses the focused control. LINE itself only lets Tab reach its text fields.
- NVDA follows focus as you move (LINE normally suppresses these notifications; the bridge turns them back on).
- Checkboxes report and change their state ("checked" / "not checked").
- Clickable texts such as "Log in with smartphone >" are links; after one switches the screen, focus moves to the first field of the new screen.
- Entering the login window reads its instructions (for example the QR-code instructions); NVDA+B reads them again.
- LINE's window-shadow windows and its unnamed layout groups are hidden from object navigation.
- Main window: sidebar tabs, chat header and message-bar buttons are named. The chat list reads "Selected" before the name of the chat that is open, then name, "Pinned" for pinned chats, "Group" or "OpenChat", member count, last message, time and unread count; the friend list reads names, member counts and group sections.
- Chat list: Up/Down, Page Up/Page Down and Home/End browse chats quickly without opening them (opening a chat makes LINE pause for up to two seconds); Enter opens the chat and moves to its message input. The chat on the right changes only when you press Enter.
- Messages: each message reads as sender (or "You"), text, time and read receipt; messages without text say what they are: photo, photo album, video, sticker, LINE emoji, voice message (with its length), file (with its name and size), location (with its address), contact (with the name) or call (with its length or status). Entering the list starts at the newest message; when you come back with Tab in the same chat, it returns to the message you read last; Shift+Tab from the message input stays where the chat is scrolled to (the message read last if it is still on screen, else the first message on screen), and opening a chat with Enter keeps LINE's place, for example its first unread message (Alt+M always goes to the newest). Up/Down move one message, Page Up/Page Down about a screen; Home goes to the oldest loaded message (LINE then loads older ones; press Home again to go further back), End to the newest; pressing Home or End again reads that message again. New messages from others are announced while LINE is in front. In one-to-one chats, received messages can start with the other person's name: turn on "Show the sender's name in one-to-one chats" in NVDA's settings, category LINE MR (off by default). To hear a sender's name only when it changes, not before each of their consecutive messages, turn on "Read the sender's name only when the sender changes" there.
- Tab order in the chat list panel: Sort, Show or hide chat room (it says whether the open chat on the right is shown; hiding it narrows the window to the list), Create chat, the ad, the search field, then the chat list (Tab goes on to the open chat).
- Sort (beside the chat list's search field): its options say which one is selected (Time received or Unread). After you choose one, focus moves to the first chat of the re-sorted list. With Unread, chats with unread messages come first, so the top of the list can look the same as before when your newest chats are unread anyway.
- Searching in a chat (the Search button in the chat header): type a word and press Enter. LINE does not filter the messages: it moves the chat to the newest matching message and shows the number of matches. LINE MR reads "Result 42 of 42" and the message. Up/Down in the search field (or the Previous result / Next result buttons) go to older / newer matches; Enter starts again from the newest. Alt+M or Tab into the messages puts you on the match, so you can read the messages around it. "Show results as a list" opens all matches in a window of their own (sender, date, text); Enter on one goes to that message in the chat. "Go to date" opens a calendar.
- Tab order in an open chat: chat header buttons, the chat's note (if it has one), "Scroll to latest message", the message list, the message input, then the message bar buttons from the input outwards (Stickers and emoji, Screenshot options, Screenshot, Keep, Attach file).
- Context menus: the Applications key (or Shift+F10) on a message opens LINE's menu with focus on its first item; Up/Down and Home/End move, Enter or Space chooses, Escape closes it and returns to the message. In groups and OpenChats, on a message from someone else, the last item, "Show <name>'s profile", opens the sender's profile (added by LINE MR; it is not drawn on screen). On a message (not on dates, notices or calls), "React" (also added by LINE MR, just before the profile item) opens LINE's reaction picker: Left/Right move between Awesome, Like, Funny, Jealous, Sad and More reactions (named as in LINE on phones; LINE may change their order), Enter gives the reaction, Escape closes the picker; the reaction you already gave reads "chosen", and choosing it again takes it back. On a message you have reacted to, the item reads "Remove reaction" and takes your reaction back at once. Messages with reactions read which ones, for example "Reaction: Like", "Like 3 people" or "Reactions: Like, Funny, 5 people in all" (LINE shows only the total, not a count per reaction). Messages in Keep Memo cannot get reactions. Choosing Reply moves to the message input. While you reply, Shift+Tab from the message input reaches Cancel reply and then Go to the original message (which scrolls the chat to it); Escape in the message input also cancels the reply.
- Incoming calls: LINE MR says "Incoming call" with the caller's name, even while you work in another application. While a LINE window is in front, press Alt+A to answer or Alt+D to decline; from any other application, press NVDA+Shift+Control+A or NVDA+Shift+Control+D (Alt+A and Alt+D stay with that application). During a call, Alt+D in LINE or NVDA+Shift+Control+D from anywhere ends the call. When no LINE call is ringing, Alt+A and Alt+D do what they normally do in LINE. Focus moves to the call notification's Answer button (Tab reaches Decline; Enter or Space presses). During a call, the call window's buttons are named (End call, Mute microphone, Start video call, Mute speaker) and its texts (caller, call length) are read. Windows lowers other sounds during a call (Sound control panel, Communications tab); LINE MR keeps NVDA's speech at its normal volume (this also applies to calls in other applications).
- Pages that open in their own window are read: clicking a group's name or its member count (for example "(5)") opens the member list; members open their profile; the chat menu's Photos & videos, Links and Files open a window named after the chat. There, the arrow keys move through the grid of photos, videos and links (Left/Right one item, Up/Down one line), Page Up/Page Down, Home and End too; each photo or video reads "Photo" or "Video", and Enter opens it in LINE's viewer (Space too for links and files; a link opens in the browser). To save or share several photos and videos at once, tick them with Space: each reads "checked" or "not checked", and LINE shows a bar under the grid ("2 selected", Share, Send to Keep Memo, Download, Cancel), reached with Tab. Download asks for a folder in Windows' dialog; Cancel unticks them all and returns to the grid. For an album sent in a chat, its photos are in this grid too. The Applications key opens a menu added by LINE MR: Open; Save for photos, videos and files (LINE then asks for a folder or a file name in Windows' dialog); Copy link and Copy text for links. In LINE's video player, Play / Pause and the Position slider are reachable: Tab moves between them, Space or Enter plays or pauses, the arrow keys seek 5 seconds, Page Up/Page Down 30 seconds, Home/End go to the start / end, and the position reads like "00:12 / 00:38". The third control, Playback speed ("1.0x", from 0.2x to 2.0x), changes with Up / Down. These keys work even though LINE uses Right for the next photo or video. The thumbnail strip at the bottom reads Photo or Video. Notes (the Notes button in a group or OpenChat): the arrow keys, Home and End move from post to post, each read like "Peet, Video, 2 comments, 8 minutes ago"; Enter or Space opens the post's photo or video in the same viewer, focus starts on the player's Play / Pause, and Escape returns to the post. The Applications key on a post opens a menu: Open, Save as... (LINE's viewer opens and Windows asks where to save), Copy text (posts with text) and More options (LINE's own menu: pin as important note, edit, delete). In the viewer, Ctrl+S saves too. Focus starts on the page's first control and its texts are read. Pages that open inside the main window get focus too.
- Stickers and emoji (the message bar's button): the package strip reads "Recently used" and the package names (LINE gives the strip pictures only: the names are read from "My stickers", the sticker window's Edit button: when names are missing or the number of packages changed, LINE MR opens it by itself for about a second when the sticker window opens, then goes back); Left/Right move through it and Enter opens a package and goes to its first sticker. Stickers read "Sticker 1", ... (LINE gives no names for them); the arrow keys move through the grid. The first Enter or Space selects a sticker or emoji ("selected, press again to send") and plays LINE's preview with its sound (stickers with sound); pressing it again sends it, closes the sticker window and returns to the message input. The round down arrow over a chat that is scrolled up reads "Scroll to latest message".
- Other windows: Settings (More > Settings; its sections and sub-sections are radio buttons, combo boxes carry their label), profile settings, Albums and Notes, Search friends, and Create chat (the button below the chat list: Chat, Group chat, OpenChat). In the friend list of Create chat / Create group, friends are checkboxes: Up/Down, Page Up/Page Down and Home/End move through all friends, Space ticks one, Tab leaves the list for the chosen friends ("Remove <name>") and Next, Shift+Tab goes back to the friend read last. The group profile page has Change profile picture, Edit group name and the "Members join automatically" switch (a checkbox). Create OpenChat asks first for the OpenChat's name, keywords and category, then (after Next) for your nickname in that OpenChat; the field reads what the page is for, and the X in a field is "Clear text". Change profile picture > Create text profile: the colours are check boxes named by number and colour ("Color 4: Light pink"), Space chooses one (checked); Text color / Background color pick what the colours change; the font list is "Font". Polls open as a web page, read in browse mode.
- Picture messages (cards from official accounts such as banks) are pictures with the text drawn into them, so LINE gives no text to read: they are reported as "photo or sticker". Press NVDA+R on such a message to read its text with Windows OCR. When LINE could not download a card, it shows "Unable to load" with a "Try again" button, which is what you hear.

## Voice messages to text

Off by default. To turn it on, open NVDA's settings, category LINE MR, group "Voice message transcription", check "Transcribe voice messages with Alt+Shift+T", choose a speech model and press OK. LINE MR then downloads, once, the speech recognition program whisper.cpp (5 MB) and the chosen model, and says when it is ready. "Model state" shows how far the download is. An interrupted or failed download continues the next time NVDA starts, or when you press Alt+Shift+T on a voice message. Unchecking the box offers to delete the downloaded files; choosing another model offers to delete the one used before.

Speech models (Typhoon by SCB 10X is Whisper trained further on Thai; Whisper by OpenAI knows many languages; memory = while converting, measured on an i5-1235U laptop):

- Typhoon Whisper Turbo (874 MB, the default): best for Thai, also English and Japanese; of the Typhoon models the one that needs the least memory (about 1.1 GB).
- Typhoon Whisper Medium (823 MB): Thai only (it writes English, Japanese and Chinese in Thai letters); as fast as Turbo on Thai, but about 1.5 GB of memory.
- Typhoon Whisper Large v3 (1,081 MB): Thai only (like Medium) and the most accurate for Thai, but very slow (a 36-second message took almost 10 minutes, Turbo 1.5 minutes) and about 2 GB of memory.
- Whisper Small (264 MB): small and fast, many languages, but many mistakes in Thai.
- Whisper Medium (823 MB) and Whisper Large v3 Turbo (874 MB): many languages; not trained further on Thai.
- "Browse for a model file": a whisper.cpp model you downloaded yourself (a ggml .bin file, for example from huggingface.co/ggerganov/whisper.cpp). LINE MR checks that the file is a whisper.cpp model and complete, and has the speech recognition program load it once, before using it. Other formats (.pt, .safetensors, GGUF, ONNX, faster-whisper) must be converted first; English-only models (names ending in .en) cannot transcribe other languages.

Then, on a voice message, press Alt+Shift+T, or choose "Transcribe voice message" in its menu (Applications key). A dialog asks for the speech model (the one chosen here is kept for next time; one not downloaded yet is downloaded, then press Alt+Shift+T again) and the language of the message ("Detect automatically" by default; choosing the language is faster and more reliable, and Chinese is sometimes taken for Thai when detected). Check "Don't show this again" to skip the dialog; the model, the language and the question are also in the settings. After OK, a window shows what is happening, with a progress bar: getting the voice message from LINE, then converting to text with an estimated percentage (LINE MR learns how fast this computer is). When it is done, the text appears in the same window in an editable field, with Copy (copies the text as edited) and Close (Escape). The text may contain mistakes. Cancel or Escape in the window, or Alt+Shift+T in LINE, cancels while it works.

Nothing is played and nothing is sent to the internet: LINE keeps every voice message it has played or downloaded, and LINE MR converts that copy on this computer. A voice message that was never played has no copy yet: then LINE plays it once (you hear it) and LINE MR uses the file as soon as LINE has downloaded it. Converting takes a while on slower computers (on an i5-1235U laptop with Typhoon Whisper Turbo about 20 seconds for a 7-second message and 1.5 minutes for a 36-second one). Needs 64-bit Windows 10 version 2004 or later.

| Alt+F | Move to the search field of the chat list or friend list |

| Alt+I | Move to the message input of the open chat |

| Delete | In the messages: delete the selected message (as Delete in the message's menu; LINE deletes it only on this computer) |
| Shift+Delete | In the messages: unsend the selected message (as Unsend in the message's menu) |

| Alt+Shift+T | In the messages: turn the selected voice message into text (turn it on in the settings first; again: cancel) |

| NVDA+Alt+1 … NVDA+Alt+9 | Read a recent message (1 = newest) |
| Alt+A in LINE, NVDA+Shift+Control+A anywhere | Answer an incoming LINE call |
| Alt+D in LINE, NVDA+Shift+Control+D anywhere | Decline an incoming LINE call; during a call, end it |
| NVDA+Shift+Control+L | Report whether the LINE MR bridge is running (and offer to install it); press twice to copy a report for the developer to the clipboard |

Commands can be changed under NVDA menu, Preferences, Input gestures, category "LINE MR". Alt+R, Delete, Shift+Delete, Alt+T and Ctrl+S act only in the messages; anywhere else (for example in the message input) the keys work as usual. They choose LINE's own item in the message's menu; if the message has no such item (for example Unsend on someone else's message), the menu stays open. Ctrl+S saves a text message whole, also a long one: LINE MR uses LINE's Copy and then puts back what the clipboard held (Windows' clipboard history, Windows+V, keeps the message).

## If LINE MR does not work

Press NVDA+Shift+Control+L in LINE. LINE MR says what is wrong and, where it can, offers to fix it:

- **The bridge is not installed / an older bridge is installed / LINE must be restarted:** choose Yes; LINE closes and starts again with the bridge. Closing LINE's window does not quit LINE (it keeps running in the notification area), so a LINE started before the bridge was installed keeps running without it until it is restarted; LINE MR asks again when you return to LINE (after No: 10 minutes later, or at once with NVDA+Shift+Control+L).
- **LINE is installed for all users** (in Program Files): Windows asks for administrator permission to add the bridge to LINE's folder. Allow it.
- **LINE started without the LINE MR bridge:** after installing, LINE MR checks that LINE really loaded the bridge. If it did not, Windows or antivirus software blocked it. When Windows 11 **Smart App Control** is on, it blocks the bridge (the file is not signed) and LINE MR cannot work; it can be turned off in Windows Security, App & browser control (Windows cannot turn it on again without a reinstall). Antivirus software may also delete or block `line_a11y.dll`: allow the file, then press NVDA+Shift+Control+L in LINE again.
- **This version of LINE is not supported:** LINE is too old for the bridge. Update LINE.
- **Messages are read as "Photo or sticker" or not at all, but buttons work:** LINE closed unexpectedly twice in a row, so the bridge stopped reading message contents to keep LINE stable. Quit LINE normally (from its menu or the notification area) and start it again.

To report a problem, press NVDA+Shift+Control+L **twice** in LINE. LINE MR copies a short report to the clipboard (versions of NVDA, Windows, LINE and Qt, where LINE is installed, the bridge's state and its start-up log, without chat contents and with your user folder replaced by `%USERPROFILE%`). Paste it into your message or GitHub issue.

## How the bridge works

The bridge is `line_a11y.dll`, a Qt platform-theme plugin placed in `%LOCALAPPDATA%\LINE\bin\current\platformthemes`, with a copy for LINE's call program (`LineCall.exe`, which shows incoming calls and the call window) in `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<version>\platformthemes`, and one for LINE's photo and video viewer (`LineMediaPlayer.exe`) in `%LOCALAPPDATA%\LINE\Data\plugin\LineMediaPlayer\<version>\platformthemes`. LINE's Qt loads it at start-up; it returns no theme (so LINE looks exactly the same) and installs accessibility interfaces for LINE's custom widgets. It reads text by recording what each widget paints, so it does not depend on LINE's internal memory layout. No LINE files are modified. Removing LINE MR in NVDA's Add-on Store also removes these DLLs and the folder `%LOCALAPPDATA%\LineMR` (logs, settings) when NVDA restarts; a LINE that is running keeps the bridge until LINE quits. For LINE installed for all users (Program Files), delete the DLL in LINE's folder yourself.

Logs: `%LOCALAPPDATA%\LineMR\logs\bridge.log`.
