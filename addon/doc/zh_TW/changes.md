# LINE MR 新功能

## 版本 0.5.4

### 長訊息
- 在長訊息的全文(「查看更多」)中,NVDA 只在作者自己換行的地方說「換行」,與 Word 一樣。上下方向鍵仍按 LINE 顯示的行移動。

### 訊息
- 一些帶連結的訊息(例如 YouTube 連結)被讀成「通話」。現在只有 LINE 的通話訊息讀作「通話」;以前讀作「照片或貼圖」的視訊通話也讀作「通話」。

### 聊天列表
- 目前開啟的聊天在名稱前讀「已選取」,置頂的聊天在名稱後讀「已置頂」。

### 建立聊天(聊天、群組聊天、社群)
- 選擇好友頁面開啟時焦點在搜尋欄位。上下方向鍵、Page Up/Page Down 和 Home/End 在所有好友之間移動,按空白鍵勾選。按 Tab 離開列表,前往已選好友(「移除 <名字>」)和「下一步」。按 Shift+Tab 回到最後朗讀的好友。
- 群組個人檔案設定頁面的按鈕都有名稱:更換大頭貼、更換背景圖片和編輯群組名稱。「成員自動加入」是核取方塊,按空白鍵切換。
- 建立社群:關鍵字欄位和類別都有名稱,欄內的 X 讀作「清除文字」。按「下一步」後,焦點移到「你在此社群中的暱稱」,並朗讀該頁面的用途。
- 建立文字大頭貼(更換大頭貼 > 建立文字大頭貼):顏色是帶編號和顏色名稱的核取方塊(「顏色 4: 淺粉紅色」),按空白鍵選擇。「文字顏色 / 背景顏色」決定顏色改變的對象。字型列表名為「字型」。

### 記事本
- 朗讀記事本(群組和社群)中的貼文:作者、照片或影片、回應和留言數以及時間。方向鍵逐則移動貼文;按 Enter 在 LINE 的影片播放器中播放貼文的影片(焦點在播放/暫停),按 Esc 返回貼文。
- 在貼文上按應用程式鍵開啟選單:開啟、另存新檔...、複製文字和更多選項(LINE 的選單)。在 LINE 的檢視器中按 Ctrl+S 儲存照片或影片。

### 設定
- 在 NVDA 設定的 LINE MR 類別中新增了這個「新功能」按鈕。

## 版本 0.5.3
- 訊息功能表(應用程式鍵)新增「回應」,並朗讀訊息上的回應。
- 貼圖組按名稱朗讀。第一次按 Enter 選擇貼圖或表情並預覽,第二次按 Enter 傳送。
- 在群組中,訊息功能表有「查看 <名字> 的個人資料」。朗讀聊天內搜尋的結果。
- 用方向鍵瀏覽聊天的照片、影片、連結和檔案,按 Enter 開啟。在影片播放器中,按空白鍵播放或暫停,方向鍵快轉或倒轉。
- 通話時 LINE 降低其他聲音,NVDA 的音量保持不變。視訊通話視窗朗讀鏡頭和麥克風是否開啟。

## 版本 0.5.2
- 在含有連結的訊息上按 Enter,在瀏覽器中開啟連結。
- 在語音訊息、檔案或照片上按應用程式鍵,開啟該訊息自己的功能表。
- 按 Tab 回到訊息列表時,回到最後朗讀的訊息。逐行朗讀長訊息更快。

## 版本 0.5.1
- 按 Enter 或空白鍵開啟訊息的內容(語音、影片、照片、檔案)。
- LINE 的照片和影片檢視器中也可使用。聊天資料夾分頁可以篩選列表。
- 可以在更多電腦上安裝。按兩次 NVDA+Shift+Control+L 複製給開發者的報告。

## 版本 0.5.0
- 像記事本一樣逐行朗讀長訊息。
- Alt+F 移到搜尋欄位。Alt+A / Alt+D 接聽或拒絕來電。
- 支援日文、簡體中文和繁體中文。

## 版本 0.4.5
- 完整朗讀長訊息。變更了聊天列表面板的 Tab 順序。

## 版本 0.4.4
- 根據 LINE 自己的圖示辨識影片、檔案、位置和貼圖。

## 版本 0.4.3
- 提示來電並可以接聽。語音訊息與長度一起朗讀。Alt+C 移到聊天列表。
