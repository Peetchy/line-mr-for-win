# LINE MR 新功能

## 版本 0.5.6

### 快速鍵
- 訊息列表中的 Alt+T 現在用於翻譯所選訊息（LINE 訊息功能表中的「翻譯」）；語音訊息轉文字改為 Alt+Shift+T。

### 語音訊息轉文字
- 新功能：在語音訊息上按 Alt+Shift+T（或在其功能表中選擇「將語音訊息轉為文字」），在本機將其轉為文字；文字在視窗中顯示，可閱讀、編輯和複製。預設為關閉：在 NVDA 設定的 LINE MR 類別中開啟後，會一次下載在那裡選擇的語音模型。共 6 個模型：Typhoon Whisper Turbo（874 MB，預設：最適合泰語，也適用於英語和日語，在 Typhoon 模型中記憶體最少）、Typhoon Whisper Medium 和 Large v3（僅限泰語；Large v3 最準確，但非常慢），以及 OpenAI 的 Whisper Small、Medium、Large v3 Turbo（多種語言）；也可用「選擇模型檔案」使用您自己的 whisper.cpp 模型，LINE MR 會在使用前檢查。每次轉換前的對話方塊會詢問模型和語言。請參閱指南「語音訊息轉文字」。

### 儲存訊息
- 新功能：在訊息列表中按 Ctrl+S 儲存所選訊息。相片、影片、檔案和語音訊息：使用 LINE 的「另存新檔」（LINE 會詢問儲存位置）。文字訊息（完整儲存，長訊息也一樣）、位置和聯絡人：儲存為文字檔（.txt），LINE MR 會詢問儲存位置。貼圖、通話、日期和通知：LINE MR 會告知無法儲存。在其他位置 Ctrl+S 照常運作，可在 NVDA 的輸入手勢中變更。

### 相片和影片
- 現在可以一次儲存或分享多張相片和多部影片 (#9):在聊天的「照片和影片」視窗(聊天選單)中,按空白鍵勾選游標所在的項目,NVDA 會讀出是否已勾選;按 Tab 可到達格狀列表下方 LINE 的一列(已選取的數量、分享、傳送至 Keep 筆記、下載、取消)。下載會詢問資料夾;取消會取消全部勾選並返回格狀列表。Enter 仍然開啟項目。聊天中傳送的相簿裡的相片也在這裡:LINE 本身也只能在這個視窗中一次儲存多張相片。

### 聊天列表
- 未讀數讀作「3 則未讀訊息」（原為「3 則未讀」），仍在聊天列的末尾。
- 群組和社群會在聊天名稱後讀出類型：「DHCB, 群組, 37 位成員, ...」、「English talk, 社群, ...」（#5）。官方帳號無法與好友區分：LINE 沒有提供可區分的資訊。

### 設定
- NVDA 設定的「LINE MR」類別顯示橋接元件是否在執行,並有按鈕可中斷它(照原樣使用 LINE,不帶 LINE MR)或重新連線。兩種情況下 LINE 都會重新啟動。
- 在 NVDA 的附加元件商店中移除 LINE MR 時,現在也會從 LINE、其通話程式和相片檢視器中移除橋接元件,並刪除 LINE MR 的資料夾 `%LOCALAPPDATA%\LineMR`。正在執行的 LINE 會繼續使用橋接元件,直到結束。

### 訊息
- 長訊息和部分收到的訊息的功能表中沒有「回應」：它們被誤認為通知，已修正（#3）。
- 用 Enter 開啟聊天時保持 LINE 的位置(例如第一則未讀訊息),不再跳到最新的訊息;從訊息輸入欄按 Shift+Tab 回到訊息時停留在畫面上(最後閱讀的訊息仍可見時停在該訊息,否則停在畫面上的第一則)。由 wengweng0312 貢獻(#20)。
- 在訊息列表中,Alt+R 回覆選取的訊息並移到訊息輸入框,Delete 刪除,Shift+Delete 收回(即 LINE 訊息功能表中的項目;LINE 的確認由你自己回答)。在其他地方這些鍵照常使用,可在 NVDA 的輸入手勢中變更(由 wengweng0312 貢獻)。
- 在訊息功能表中選擇「回覆」會移到訊息輸入框(由 wengweng0312 貢獻)。
- 回覆時可以到達訊息輸入框上方的列:在訊息輸入框按 Shift+Tab 會到「取消回覆」和「前往原訊息」。取消後回到訊息輸入框。
- NVDA 設定的「LINE MR」類別中的新選項「在單獨對話中顯示對方姓名」:在對方的訊息前讀出對方的姓名(預設關閉)。LINE 沒有顯示時間的你自己的長訊息也會讀作你的(由 wengweng0312 貢獻)。
- 在聊天列表中按 Enter 會停留在所開啟聊天的訊息輸入框:LINE 有時在聊天載入完成後把焦點移到訊息列表。在開啟的聊天中,Tab 總是依序到訊息列表、訊息輸入框,然後是其下方的按鈕。
- 群組聊天中的 @ 提及:輸入 @ 後,上下方向鍵讀出 LINE 建議的成員,繼續輸入可篩選,按 Enter 選擇。以前方向鍵在這裡沒有作用(由 wengweng0312 貢獻)。在訊息輸入框中,所選成員讀作「@姓名」(以前 NVDA 什麼也不讀)。
- 訊息讀出 LINE 自己的文字(LINE 26.6 及更新版本):每則訊息都有傳送者和時間,回覆完整,檔名完整,也包括不在螢幕上的訊息。LINE 沒有說明的部分由 LINE MR 補充:你自己的訊息前的「你」、貼圖和通話以及表情回應(由 wengweng0312 貢獻)。橋接元件讀取的長度(通話,以及沒有 LINE 文字的語音訊息和影片)讀作「7秒」「10分鐘54秒」,而不是「00:07」「10:54」。
- 訊息也會讀出 LINE 自身文字中沒有的內容:檔案大小和下載期限、連結預覽的標題、地址前的「位置資訊」、「聯絡人」及其名稱,以及用「相簿」代替「照片」。回覆先讀回覆內容:「X, 回覆 Y：<回覆>, 原始訊息：<引用>」。在 Keep 筆記中每則訊息都讀作「你」;並能辨識日文和中文 LINE 的時間與已讀狀態,因此在這些語言中你自己的訊息也讀作「你」。
- NVDA 設定的「LINE MR」類別中的新選項「僅在傳送者改變時朗讀傳送者姓名」(預設關閉):同一人的連續訊息直接從內容開始。

## 版本 0.5.5

### 更新
- 從 NVDA 附加元件商店安裝時,更新交給附加元件商店:LINE MR 不再檢查 GitHub,設定中也會說明。

### 焦點醒目顯示
- 為了低視能使用者:帶黑邊的黃色框顯示 LINE 中哪個控制項取得焦點(也包括聊天、訊息和選單項目)。可以在 NVDA 設定的 LINE MR 類別中變更色彩和寬度,或將其關閉。

### 修正
- 在 NVDA 2025.4 或更早版本(32 位元 NVDA)中,LINE MR 已經可用卻反覆要求重新啟動 LINE。現在能正確識別 LINE 已在執行 LINE MR。
- 在訊息輸入框和其他文字框中,上/下方向鍵朗讀螢幕上顯示的行:自動換行的長段落逐行朗讀,不再每行都重複整段;空行朗讀為「空白」,不再朗讀上一行。
- 在訊息輸入框中逐行閱讀時,上/下方向鍵不再使焦點移走(移到上方 LINE 的貼圖和表情貼推薦)。
- 在已載入的最舊訊息上按上方向鍵,LINE 會載入更早的訊息,並可繼續向上(由 wengweng0312 貢獻)。
- 用鍵盤變更的設定核取方塊(例如 通知 > 顯示訊息內容)現在會被儲存(由 wengweng0312 貢獻)。
- 能辨識 LINE 分成幾塊繪製的語音訊息,按 Enter 或空白鍵即可播放(由 wengweng0312 貢獻)。
- 繁體中文 LINE:已讀標記(已讀)和時間(下午 2:49)在訊息末尾朗讀,內容為「已讀」的收到訊息不會被當作已讀標記(由 Keyang556 貢獻)。

## 版本 0.5.4

### 長訊息
- 在長訊息的全文(「查看更多」)中,NVDA 只在作者自己換行的地方說「換行」,與 Word 一樣。上下方向鍵仍按 LINE 顯示的行移動。

### 訊息
- 一些帶連結的訊息(例如 YouTube 連結)被讀成「通話」。現在只有 LINE 的通話訊息讀作「通話」;以前讀作「照片或貼圖」的視訊通話也讀作「通話」。

### 聊天列表
- 目前開啟的聊天在名稱前讀「已選取」,置頂的聊天在名稱後讀「已置頂」。

### 建立聊天(聊天、群組聊天、社群)
- 選擇好友頁面開啟時焦點在搜尋欄位。上下方向鍵、Page Up/Page Down 和 Home/End 在所有好友之間移動,按空白鍵勾選。按 Tab 離開列表,前往已選好友(「移除 <名字>」)和「下一步」。按 Shift+Tab 回到最後朗讀的好友。
- 群組個人檔案設定頁面的按鈕都有名稱:更換大頭貼、更換背景圖片和編輯群組名稱。「成員自動加入」是核取方塊,按空白鍵切換。
- 建立社群:關鍵字欄位和類別都有名稱,欄內的 X 讀作「清除文字」。按「下一步」後,焦點移到「你在此社群中的暱稱」,並朗讀該頁面的用途。
- 建立文字大頭貼(更換大頭貼 > 建立文字大頭貼):顏色是帶編號和顏色名稱的核取方塊(「顏色 4: 淺粉紅色」),按空白鍵選擇。「文字顏色 / 背景顏色」決定顏色改變的對象。字型列表名為「字型」。

### 記事本
- 朗讀記事本(群組和社群)中的貼文:作者、照片或影片、回應和留言數以及時間。方向鍵逐則移動貼文;按 Enter 在 LINE 的影片播放器中播放貼文的影片(焦點在播放/暫停),按 Esc 返回貼文。
- 在貼文上按應用程式鍵開啟選單:開啟、另存新檔...、複製文字和更多選項(LINE 的選單)。在 LINE 的檢視器中按 Ctrl+S 儲存照片或影片。

### 設定
- 在 NVDA 設定的 LINE MR 類別中新增了這個「新功能」按鈕。

## 版本 0.5.3
- 訊息功能表(應用程式鍵)新增「回應」,並朗讀訊息上的回應。
- 貼圖組按名稱朗讀。第一次按 Enter 選擇貼圖或表情並預覽,第二次按 Enter 傳送。
- 在群組中,訊息功能表有「查看 <名字> 的個人資料」。朗讀聊天內搜尋的結果。
- 用方向鍵瀏覽聊天的照片、影片、連結和檔案,按 Enter 開啟。在影片播放器中,按空白鍵播放或暫停,方向鍵快轉或倒轉。
- 通話時 LINE 降低其他聲音,NVDA 的音量保持不變。視訊通話視窗朗讀鏡頭和麥克風是否開啟。

## 版本 0.5.2
- 在含有連結的訊息上按 Enter,在瀏覽器中開啟連結。
- 在語音訊息、檔案或照片上按應用程式鍵,開啟該訊息自己的功能表。
- 按 Tab 回到訊息列表時,回到最後朗讀的訊息。逐行朗讀長訊息更快。
