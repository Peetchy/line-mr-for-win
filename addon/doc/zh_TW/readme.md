# LINE MR (Line Mai Roo) for NVDA

LINE MR 讓 [LINE for Windows](https://line.me) 可以搭配 NVDA 使用。

LINE 自行繪製按鈕和文字,因此它本身幾乎不向螢幕閱讀器提供任何資訊:按鈕沒有名稱,文字也無法朗讀。LINE MR 在 LINE 中加入一個小型無障礙橋接元件,為 LINE 的控制項提供名稱、角色和操作,並提供一個 NVDA 應用程式模組,整理 NVDA 朗讀的內容。

## 安裝

**建議:安裝 [Microsoft Store 版 LINE](https://apps.microsoft.com/detail/XPFCC4CD725961)**(LY Corporation 發行的「LINE Desktop」;也可以在 Microsoft Store 應用程式中搜尋「LINE」)。LINE MR 以 Microsoft Store 版開發和測試,因此相容性最好。它會把 LINE 安裝到 `%LOCALAPPDATA%\LINE` 並自動保持更新。從其他來源取得的 LINE 可能安裝在別的位置或是不同的版本,橋接元件可能無法安裝或無法運作。

1. 安裝本附加元件並重新啟動 NVDA。
2. 啟動 LINE(或切換到 LINE)。LINE MR 會詢問是否將橋接元件安裝到 LINE 中,請選擇 **是**。LINE 會關閉並帶著橋接元件重新啟動。

LINE 更新後可能需要重新安裝橋接元件;LINE MR 會自動發現並再次詢問。

## 更新 LINE MR

NVDA 啟動時,LINE MR 會在 GitHub 上檢查是否有新版本。如果有,會出現對話方塊,提供 **立即更新**、**稍後** 或 **略過此版本**。選擇「立即更新」會下載新版本並交給 NVDA,NVDA 會請你確認安裝,然後重新啟動 NVDA。要關閉檢查或立即檢查:NVDA 功能表,偏好,設定,類別「LINE MR」。命令「檢查 LINE MR 的新版本」(預設沒有按鍵)可以在「輸入手勢」中指定按鍵。

## 目前可以做到的

- 登入視窗:電子郵件和密碼欄位、登入按鈕、「自動登入」核取方塊、QR 碼說明以及標題列按鈕都有名稱。
- 只有圖示的按鈕會依照圖示取得名稱,使用 LINE 本身的介面語言(繁體中文、簡體中文、英文、泰文或日文)。
- 鍵盤:Tab 和 Shift+Tab 可以依朗讀順序到達每個按鈕、核取方塊和連結(先是視窗內容,最後是標題列按鈕);空白鍵或 Enter 按下目前焦點所在的控制項。LINE 本身只允許用 Tab 到達文字欄位。
- 移動時 NVDA 會跟隨焦點(LINE 通常會封鎖這些通知,橋接元件將其重新開啟)。
- 核取方塊會報告並切換狀態(「已核取」/「未核取」)。
- 「使用智慧型手機登入 >」這類可點選的文字會作為連結;當它切換畫面後,焦點會移到新畫面的第一個欄位。
- 進入登入視窗時會朗讀其說明(例如 QR 碼說明);按 NVDA+B 可再次朗讀。
- LINE 用於視窗陰影的視窗和沒有名稱的版面群組不會出現在物件導覽中。
- 主視窗:側邊欄分頁、聊天標題列和訊息列的按鈕都有名稱。聊天列表朗讀名稱、成員數、最後一則訊息、時間和未讀數;好友列表朗讀名稱、成員數和群組標題。
- 聊天列表:上下方向鍵、Page Up/Page Down 和 Home/End 可以快速瀏覽聊天而不開啟它們(開啟聊天會讓 LINE 停頓最多約兩秒);Enter 開啟聊天並移到其訊息輸入框。右側的聊天只有在按 Enter 時才會切換。
- 訊息:每則訊息依傳送者(或「你」)、內容、時間和已讀狀態朗讀;沒有文字的訊息會說明其類型:照片、相簿、影片、貼圖、LINE 表情貼、語音訊息(含長度)、檔案(含名稱和大小)、位置資訊(含地址)或通話(含長度或狀態)。進入列表時(Tab、Shift+Tab 或 Alt+M)從最新的訊息開始。上下方向鍵移動一則訊息,Page Up/Page Down 約移動一頁;Home 到已載入的最早訊息(LINE 隨後會載入更早的訊息,再按 Home 可繼續往前),End 到最新訊息;再次按 Home 或 End 會重新朗讀該訊息。LINE 在前景時,會播報他人傳來的新訊息。
- 聊天列表面板中的 Tab 順序:排序、顯示或隱藏聊天列表、建立聊天、廣告、搜尋欄位,然後是聊天列表(再按 Tab 進入已開啟的聊天)。
- 已開啟聊天中的 Tab 順序:聊天標題列按鈕、聊天的記事本(如果有)、「捲動到最新訊息」、訊息列表、訊息輸入框,然後是訊息列按鈕(從輸入框向外:貼圖和表情貼、截圖選項、截圖、Keep、附加檔案)。
- 快顯功能表:在訊息上按應用程式鍵(或 Shift+F10)會開啟 LINE 的功能表,焦點在第一個項目上;上下方向鍵和 Home/End 移動,Enter 或空白鍵選擇,Esc 關閉並返回訊息。
- 來電:即使你在其他應用程式中工作,LINE MR 也會朗讀「來電」和來電者的名字。在任何應用程式中按 Alt+A 接聽,按 Alt+D 拒絕(沒有 LINE 來電時,這些按鍵在該應用程式中保持原有功能;NVDA+Shift+Control+A / D 同樣可用)。通話期間,當 LINE 視窗在前景時按 Alt+D 結束通話(在任何位置可按 NVDA+Shift+Control+D)。焦點會移到來電通知的「接聽」按鈕(按 Tab 到「拒絕」;Enter 或空白鍵按下)。通話期間,通話視窗的按鈕(結束通話、關閉麥克風、開始視訊通話、關閉喇叭)都有名稱,並會朗讀其文字(對方、通話時間)。
- 在獨立視窗中開啟的頁面會被朗讀:點選群組名稱或其成員數(例如「(5)」)會開啟成員列表;從成員可以開啟其個人檔案;聊天選單中的「照片和影片」「連結」和「檔案」會在以聊天名稱命名的視窗中開啟。焦點從頁面的第一個控制項開始,並會朗讀頁面文字。在主視窗內開啟的頁面也會取得焦點。
- 其他視窗:設定(更多 > 設定;其各部分和子部分為選項按鈕,下拉式方塊帶有標籤)、個人檔案設定、相簿和記事本、搜尋好友,以及建立群組(好友為核取方塊:按空白鍵勾選)。投票以網頁形式開啟,在瀏覽模式下朗讀。
- 圖片訊息(銀行等官方帳號傳送的卡片)的文字是畫在圖片裡的,LINE 不提供可朗讀的文字,因此會報告為「照片或貼圖」。在這類訊息上按 NVDA+R,可用 Windows OCR 辨識其文字。如果 LINE 無法下載卡片,會顯示「無法載入」和「重試」按鈕,你聽到的就是這些內容。

## 命令

| 命令 | 操作 |
|---|---|
| Alt+1 / Alt+2 / Alt+3 | 好友 / 聊天 / 加入好友 分頁 |
| Alt+C | 移到聊天列表(如有需要先切換到聊天分頁) |
| Alt+L | 移到聊天列表或好友列表(目前顯示的那個) |
| Alt+F | 移到聊天列表或好友列表的搜尋欄位 |
| Alt+M | 移到已開啟聊天的訊息 |
| Alt+I | 移到已開啟聊天的訊息輸入框 |
| NVDA+Alt+1 … NVDA+Alt+9 | 朗讀最近的訊息(1 = 最新) |
| Alt+A(或 NVDA+Shift+Control+A) | 接聽 LINE 來電(在任何應用程式中都可用) |
| Alt+D(或 NVDA+Shift+Control+D) | 拒絕 LINE 來電(在任何應用程式中都可用);通話期間結束通話(Alt+D 需 LINE 視窗在前景,NVDA+Shift+Control+D 在任何位置) |
| NVDA+Shift+Control+L | 報告 LINE MR 橋接元件是否在執行(並提供安裝);按兩次將給開發者的報告複製到剪貼簿 |

可以在 NVDA 功能表,偏好,輸入手勢,類別「LINE MR」中修改命令。

| 訊息 | 上下方向鍵:上一則 / 下一則訊息;Page Up/Page Down:約一頁;Home:已載入的最早訊息(再按:載入更早的訊息);End:最新訊息;應用程式鍵或 Shift+F10:訊息選單;Enter 或空白鍵:顯示長訊息的全文(可以像在記事本中一樣逐行閱讀,按 Escape 返回),播放或暫停語音訊息,在 LINE 的檢視器中開啟相片或影片(按 Tab 在按鈕和縮圖之間移動,按 Escape 關閉並返回聊天),用對應的程式開啟檔案(PDF、Word 等) |
| 訊息選單 | 上下方向鍵、Home/End 移動;Enter 或空白鍵選擇;Esc 關閉並返回訊息 |
| 通話 | 在「接聽」/「拒絕」上按 Enter 或空白鍵;在任何應用程式中 Alt+A 接聽、Alt+D 拒絕;在 LINE 中按 Alt+D 結束目前的通話 |

## 如果 LINE MR 無法運作

在 LINE 中按 NVDA+Shift+Control+L。LINE MR 會說明問題所在,並在可能時提供修復:

- **橋接元件未安裝 / 安裝的是舊版橋接元件 / 需要重新啟動 LINE:** 選擇 **是**,LINE 會關閉並帶著橋接元件重新啟動。關閉 LINE 的視窗並不會結束 LINE(它會繼續在通知區域中執行),因此在安裝橋接元件之前啟動的 LINE 會一直在沒有橋接元件的情況下執行,直到重新啟動;回到 LINE 時 LINE MR 會再次詢問(選擇「否」後 10 分鐘再問,按 NVDA+Shift+Control+L 則立即詢問)。
- **LINE 是為所有使用者安裝的**(在 Program Files 中):Windows 會要求系統管理員權限,以便把橋接元件加入 LINE 的資料夾。請允許。
- **LINE 啟動時沒有載入 LINE MR 橋接元件:** 安裝後,LINE MR 會檢查 LINE 是否真的載入了橋接元件。如果沒有,表示被 Windows 或防毒軟體封鎖了。Windows 11 的 **智慧型應用程式控制** 開啟時會封鎖橋接元件(檔案沒有簽章),LINE MR 無法運作;可以在 Windows 安全性的「應用程式與瀏覽器控制」中關閉(關閉後除非重新安裝 Windows,否則無法再次開啟)。防毒軟體也可能刪除或封鎖 `line_a11y.dll`:請允許該檔案,然後在 LINE 中再按一次 NVDA+Shift+Control+L。
- **LINE MR 不支援此版本的 LINE:** LINE 版本太舊,無法載入橋接元件。請更新 LINE。
- **按鈕可以朗讀,但訊息被讀成「照片或貼圖」或無法朗讀:** LINE 連續兩次意外關閉,為了讓 LINE 保持穩定,橋接元件暫停讀取訊息內容。請正常結束 LINE(從選單或通知區域),然後再啟動。

要回報問題,請在 LINE 中按 **兩次** NVDA+Shift+Control+L。LINE MR 會把一份簡短的報告複製到剪貼簿(NVDA、Windows、LINE 和 Qt 的版本,LINE 的安裝位置,橋接元件的狀態和啟動記錄;不含聊天內容,你的使用者資料夾會替換為 `%USERPROFILE%`)。把它貼到你的訊息或 GitHub issue 中。

## 橋接元件的運作方式

橋接元件是 `line_a11y.dll`,一個放在 `%LOCALAPPDATA%\LINE\bin\current\platformthemes` 中的 Qt 平台佈景主題外掛;LINE 的通話程式(顯示來電和通話視窗的 `LineCall.exe`)使用的副本放在 `%LOCALAPPDATA%\LINE\Data\plugin\LineCall\<版本>\platformthemes` 中,LINE 的相片和影片檢視器(`LineMediaPlayer.exe`)使用的副本放在 `%LOCALAPPDATA%\LINE\Data\plugin\LineMediaPlayer\<版本>\platformthemes` 中。LINE 的 Qt 在啟動時載入它;它不回傳任何佈景主題(因此 LINE 的外觀完全不變),只為 LINE 的自訂控制項加入無障礙介面。它透過記錄每個控制項繪製的內容來讀取文字,因此不依賴 LINE 的內部記憶體配置。不會修改任何 LINE 檔案;要移除它,刪除這些 DLL 即可。

記錄檔:`%LOCALAPPDATA%\LineMR\logs\bridge.log`。

LINE MR 是一個獨立專案,與 LY Corporation / LINE 無關聯,也未獲其認可。
